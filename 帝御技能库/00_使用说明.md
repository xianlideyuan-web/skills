# 帝御技能库 · 使用说明

> 版本：v1.07（迭代：众观·多视角 + 判据卡 + 决策加固 + AI规范）
> 更新：2026-10-05

## 这是什么

帝御不是单个文件，而是一套完整的技能库（供 Agent / MCP / 调度器调用）。本目录结构如下：

```
帝御技能库/
├── 00_使用说明.md                        ← 本文件
├── 01_帝御主框架/帝御-SKILL-v1.07.md     ← 帝御主框架（心法层+主见层+御势层+御物法则+众观·多视角+判据卡+决策加固+万法归宗）
├── 02_调度器/帝御-调度器-router.md       ← 帝御唯一入口，负责需求→层/诀/典的路由（含众观与决策加固触发）
├── 03_典籍子技能/                        ← 26部典籍，各自独立可调用
├── 04_历史版本/                          ← 旧版本归档（命名 diyu-v<版本号>.md，Git式每版一份）
└── 经验沉淀.md                           ← 迭代记忆：历次经验教训，迭代前必读
```

## 如何使用

1. **入口**：先加载 `02_调度器/router.md`，它判断当前需求属于哪一层、哪一诀、哪部典籍，以及是否触发「众观·多视角」或「决策加固」。
2. **主框架**：常规决策/心性/博弈分析，加载 `01_帝御主框架/帝御-SKILL-v1.07.md` 即可（含完整体系+26部精华映射+判据卡+决策加固）。
3. **子技能**：当需求高度契合某部典籍（如谈判→鬼谷子、资源分配→管子、僵局→三十六计、识人→人物志、时机→周易），按调度器指示加载对应文件。
4. **多人/家庭/团队决策**：必须走「众观·多视角」——每个利益相关者单独跑一遍完整帝御（每人一张视角卡），再汇总比对（共识/冲突/否决/损益）定策；家庭决策配偶一票否决。
5. **重大/高风险决策**（辞职/创业/大额投入）：除常规推演外必填「决策加固」——概率区间+期望值、止损线、财务熔断（生存期计算器三情景+熔断线反推）。
6. **历史版本**：每次版本升级，旧版归档到 `04_历史版本/`，命名 `diyu-v<版本号>.md`；仅修缮不升版本时不归档。
7. **经验沉淀**：每次迭代/修缮前先读 `经验沉淀.md`，避免重复踩坑。

## 版本归档规则

- **迭代**（用户说明"迭代"，版本号递增）：先归档旧版到 `04_历史版本/`，再写入新版主文件。
- **修缮**（默认，不升版本号）：不归档，只在版本记录追加「修缮补充」说明。
- 判断规则：用户每次更新会说明是「修缮」还是「迭代」；默认为修缮，说明为迭代则升版。
