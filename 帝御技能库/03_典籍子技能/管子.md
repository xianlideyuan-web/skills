# 《管子》· 帝御子技能

## 一、典籍定位

《管子》是帝御凝本存资层的"资源调度学"：它把治国理政的轻重之术（管仲治齐的经济调控）降维成个人与项目的资源管理法——怎么分配有限的资金、时间、精力，怎么在丰年积储、在荒年取用，怎么让资源出口集中而非散乱。适用于财务规划、精力管理、项目资源调度，是把"凝格恒戮"落到"钱往哪流、时间给谁"的工具书。

## 二、核心公理

- **固本而知礼节**：「仓廪实则知礼节，衣食足则知荣辱。」（牧民）帝御化：先喂饱基本盘，再谈上层追求——存款安全垫、身体健康、核心技能、情绪稳定是"仓廪"，没夯实之前，任何宏大规划都是空中楼阁。落判断：你现在的"仓廪"（生存底线）是满的还是空的？空则先补，满再谋进。
- **轻重调节**：「民有余则轻之，故人君敛之以轻；民不足则重之，故人君散之以重。」（国蓄）帝御化：资源如水，贵在逆周期调节——别人/自己"有余"（资源充裕、价格低迷）时收敛囤积（买入、学习、积累）；"不足"（资源紧缺、价格高涨）时释放兑现（出售、输出、变现）。落动作：低谷多囤能力与筹码，高峰多兑现收益与成果。
- **积储为先**：「一年之计，莫如树谷；十年之计，莫如树木；终身之计，莫如树人。」（权修）帝御化：长期资本（技能、人脉、身体、声誉）无法速成，必须在"用不到它"的时候就种下。落判断：你现在种的东西，是吃一年、吃十年，还是吃一辈子？十年树要现在就种，急用时种不活。
- **利出一孔**：「利出一孔者，其国无敌；出二孔者，其兵不诎；出三孔者，不可以举兵；出四孔者，其国必亡。」（国蓄）帝御化：资源出口越集中，力量越强；同时铺太多方向，每个方向都喂不饱，整体必溃。落动作：数一数自己同时在做几件事——超过两件主线，就该砍。

## 三、适用场景清单

1. 资金/时间/精力分配：多件事抢同一份资源，不知给谁。
2. 预算规划：收入有限，需要定"先保什么、再投什么"的次序。
3. 低谷囤积或高峰兑现：行情/机会处于低点，该攒还是该花。
4. 项目资源调度：团队/个人同时开多条线，需要定主次与配额。
5. 防过度分散：兴趣太多、方向太杂、精力被撕碎，需要收拢。
6. 长期规划：想做"现在没用但以后值钱"的积累（技能、作品、人脉），需要给它们排期。

## 四、推演逻辑链

1. **盘本**：列出当前全部可支配资源（钱、每周可支配时间、精力、人脉、已掌握技能），并给基本盘打分（生存底线是否安全）。
2. **定轻重**：按"轻重缓急"给资源流向排序——先保命（固本：存款/健康/主线收入），再谋进（进取：学习/副业/新产品）；基本盘不牢，进取项一律降权。
3. **调流向**：判断当前处于"有余"还是"不足"阶段——有余则敛（囤积累、练内功、低价买入），不足则散（兑现成果、输出变现、高价卖出）；逆周期操作，不随情绪追涨杀跌。
4. **种长储**：从资源池中固定划出一块"十年树"配额（如每周固定2小时、每月固定一笔钱），投入不可速成的长期资本，雷打不动。
5. **归一孔**：砍掉分散的资源出口——列出当前所有"同时进行的主线"，保留至多两件；砍掉的记入"停止清单"防止手痒重启。
6. **复盘调节**：以月/季为周期复盘，按"轻重"重新分配资源流向，验证"敛/散"时机判断是否准确，修正下一轮。

## 五、约束边界

1. 轻重之术是资源分配逻辑，不用于市场操纵、囤积居奇式的投机教唆——"敛"指能力与筹码积累，不是炒作商品。
2. 「利出一孔」是个人/项目聚焦原则，不是垄断或排他教唆；社交、学习、健康的合理多元不算"多孔"。
3. 不鼓励极端节俭：固本是为了"有底气的进取"，不是为了攒钱而牺牲生活质量与机会成本。
4. 逆周期调节需要信号依据：没有明确"低/高"信号时，用固定比例定投代替主观抄底。
5. 与帝御「俭」区分：俭是心态上的积微累势，管子是操作层的流向分配；两者配合但不过度苛责自己。

## 六、案例示例

**案例一（个人财务·轻重与固本）**：月薪有限，想同时存钱、学技能、买装备、社交。
- 背景：四件事抢一份收入，月月见底。
- 走逻辑链：盘本——收入减去固定支出后余量小，安全垫不足两个月；定轻重——先补安全垫到3个月（固本），再排学习与社交；调流向——淡季少买装备（有余则敛改投学习），旺季接单变现（不足则散）；种长储——每月固定10%投入技能学习（十年树）；归一孔——砍掉两个烧钱爱好。
- 结论：三个月后安全垫达标，学习投入带来一次副业变现，收支进入正循环。

**案例二（独立开发·利出一孔）**：一人开发者同时在维护三个项目，更新都慢、用户都流失。
- 背景：三个方向互相抢时间，没有一个跑出来。
- 走逻辑链：盘本——每周开发时间约20小时，三个项目各得6-7小时；定轻重——选数据最好、最接近变现的一个为主（固本现金流）；调流向——其余两个进入"维护不迭代"状态（有余则敛，留而不投）；归一孔——20小时集中到主项目，两个副项目暂停宣传。
- 结论：主项目两个月内完成关键版本，用户活跃翻倍，副项目日后择优复活，不再三线皆输。

## 七、与帝御体系联动

- **归层**：凝本存资层（地），主导诀「凝」（积微成势、积储固本）+「恒」（保无竭、给时间伟量）。
- **诀系**：凝 + 恒 + 俭（聚焦）。
- **调度方式**：帝御定位处境为"资源分配/预算/精力管理/防分散"时，由凝本存资层触发本子技能，按「推演逻辑链」输出资源流向方案；与主文件分工——主文件给凝格恒戮的定性框架，本文件给《管子》的定量调度操作法。
