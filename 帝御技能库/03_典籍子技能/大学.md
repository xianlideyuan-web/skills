# 《大学》· 帝御子技能

## 一、典籍定位

《大学》本是《礼记》中的一篇，经程朱表章列为「四书」之首，是帝御内炼之经中的**"次第与定止学 + 推己度人之尺"**。它的骨架是两套原文必须保留的结构：

- **三纲领**（经一章首句）：「大学之道，在明明德，在亲民，在止于至善。」——一门大人之学的全部目标，就三层：先把自己本有的光明之德擦亮（明明德），再把这份光明推及他人、让身边人日日新（亲民 / 程朱读为"新民"），最后把目标停在"至善"这一最高边界上、不再妄进。
- **八条目**（经一章）：「古之欲明明德于天下者，先治其国；欲治其国者，先齐其家；欲齐其家者，先修其身；欲修其身者，先正其心；欲正其心者，先诚其意；欲诚其意者，先致其知；致知在格物。」反过来自内而外是一条**不可颠倒的链**：格物→致知→诚意→正心→修身→齐家→治国→平天下。
- **经一章、传十章**：经一章是曾子所述孔子之言（总纲），传十章是门人（朱子定为曾子之意）逐句释经——释"明明德"二章、释"新民"一章、释"止于至善"一章、释"本末"一章、释"格物致知"一章、释"诚意"一章、释"正心修身"一章、释"修身齐家"一章、释"齐家治国平天下"（即**絜矩之道**）一章。帝御只取其义：**经是骨架，传是把骨架每一节点落到日常动作**。

它不教你想得多大，而教你**按什么顺序一步步做、在哪一步先停住、推己及人时拿什么当尺**。适用于想法泛滥、目标漂移、越级求成、临事慌乱的时刻——是把帝御「温」的煅渊路径落成"先停哪一步、再补哪一层、待人以什么为度"的工具书。

## 二、核心公理

- **三纲领是目标的三层收束**：「大学之道，在明明德，在亲民，在止于至善。」（经一章）帝御化：任何大目标都先问自己在哪一层——**明明德**（先把自己这块料修明白，认知、心态、行为先立住）→ **亲民 / 新民**（把这份明白推给身边的人、你的小团队、你的家，让他们因你而变好一点点）→ **止于至善**（追到"做得尽善"那一点就停，不贪多到把已有的赔进去）。落判断：你现在喊的"大目标"，是真的从"先把自己修好"长出来的，还是一上来就要"平天下"的空中楼阁？跳过明明德直接谈亲民平天下，就是越级。
- **八条目次第不可躐等**：「物格而后知至，知至而后意诚，意诚而后心正，心正而后身修，身修而后家齐，家齐而后国治，国治而后天下平。」（经一章）帝御化：从认知到行为、从自身到外部是一条**严格先后的因果链**——格物（看清事实）→致知（摸到规律）→诚意（真心想做）→正心（摆平心态）→修身（落到行为）→齐家（理顺身边小环境）→治国平天下（把这套复制到更大范围）。上一层没打通就跳到下一层，就是"越级求成"，必然返工。落判断：你现在急着做的事，上一层（事实看清了吗？真想做吗？心平了吗？自己行为跟上了吗？）真的通了吗？
- **知止为万端之始（止定静安虑得）**：「知止而后有定，定而后能静，静而后能安，安而后能虑，虑而后能得。」（经一章）帝御化：一切混乱的源头是"不知道止在哪"。先定目标的边界与终点（止），心才会定；定了才静得下来；静得下来才安身；安身之后才虑得周全；虑周全了才有所得。**止→定→静→安→虑→得，是六步流水，顺序错一步全乱。**落动作：乱的时候，第一步永远不是"做什么"，而是"止于何处"——把目标边界写下来。
- **壹是皆以修身为本**：「自天子以至于庶人，壹是皆以修身为本。其本乱而末治者否矣；其所厚者薄，而其所薄者厚，未之有也。」（经一章）帝御化：外部事务（齐家 / 项目 / 关系 / 团队）的一切问题，根子都在自己这一层没修好。本乱了、末头却想治好，从来没有过。事情做不顺时，别急着改外部，先回到"我自己这层哪里没到位"——认知、意愿、心态、行为，哪层虚补哪层。落判断：此刻让你痛苦的，是外部条件不够，还是自己这一层的地基没打牢？
- **诚意毋自欺（慎于独知）**：「所谓诚其意者，毋自欺也。如恶恶臭，如好好色，此之谓自慊，故君子必慎其独也。」（传六章）帝御化：别骗自己"我很想做"——嘴上想做、身体很诚实地拖延，就是意不诚。诚意的检验标准像闻臭、好色一样**本能而不伪装**：愿不愿意为它付出真实成本（时间、钱、面子、苦）。不想付成本的"想"，是自欺。而"独"处那一点点自欺，只有自己知道，故君子连独处时都不欺自己。落动作：把"我很想做X"翻译成"我愿为X每周付出__小时真实时间"，填不出数字的，就是假意诚。
- **絜矩之道（推己及人之尺）**：「所恶于上，毋以使下；所恶于下，毋以事上；所恶于前，毋以先后；所恶于后，毋以从前；所恶于右，毋以交于左；所恶于左，毋以交于右。此之谓絜矩之道。」（传十章）帝御化：絜（量）矩（尺）——拿自己当一把尺子去量待人的分寸。**你厌恶上级怎么对你，你就别那样对下级；你厌恶下级怎么敷衍你，你就别那样敷衍上级；前后左右四个方向同理。**这不是道德高调，是带队 / 齐家 / 合作里最硬的一条互惠律：你怎么被对待，你就怎么对待别人的反向操作。落判断：此刻你对待下 / 对待队友的方式，是不是正是你自己最讨厌的那种上级 / 队友的方式？是，就是矩歪了。
- **知本知至，先本后末**：「此谓知本，此谓知之至也。」（经一章 / 传五章）帝御化：万事都有本末先后——修身是本，齐治平是末；目标边界是本，动作是末。分清哪是根（必须先做）、哪是枝叶（可以后做），把力气先砸在本上。**本立而道生；知所先后，则近道矣。**落判断：你投入精力最多的那件事，是"本"还是"末"？本末倒置的努力，越勤奋越偏。

## 三、适用场景清单

1. 目标漂移：同时想要太多、三心二意，做着做着忘了当初要什么。
2. 想法泛滥：脑子里念头一个接一个，越想越乱，无从下手。
3. 越级求成：基本功没打就想做高阶成果，天天急于求成、频繁返工。
4. 临事慌乱：deadline 逼近或突发变故，心乱如麻，越急越做错。
5. 想一步登天：看到别人成果就想跳过积累直接复制，不肯做底层。
6. 长期项目卡壳：做了很久没进展，不知道该从哪一层下手补。
7. 待人 / 带队失度：对下严苛对上讨好（或反之），双标，团队不服、家人疏远。
8. 目标过大悬空：一上来就想"改变世界 / 做大作"，却不肯先把自己这块料修好。

## 四、推演逻辑链

1. **先止（定边界）**：拿出一张纸，写清这件事的"止"在哪——终点是什么、边界到哪为止、什么算"成了"（对应"止于至善"的那个至善点）。一句话说不清楚，说明目标本身还模糊，先别动手。
2. **再定（不漂移）**：对照这个边界，把当前所有正在做 / 想做的事过一遍——凡是不指向这个终点的，一律划入"暂停清单"，防止目标被新念头带跑。
3. **归三纲（定层）**：判断此刻你站在三纲领的哪一层——是还在"明明德"（修自己），还是已可"亲民"（带人 / 影响身边人），还是该"止于至善"（见好就收）。没到那一层，不抢那一层的事。
4. **走八目次第检验（定位卡点）**：按链条逐层自评，找出第一个"没打通"的环节——①格物：事实看清了吗？②致知：背后规律摸到了吗？③诚意：真心想做、愿付成本吗？④正心：心态摆正、不躁不馁吗？⑤修身：每天的具体行动跟上了吗？⑥齐家：身边小环境理顺了吗？
5. **补卡层（不跨层）**：卡在格致层就回去补认知 / 调研，不要空喊决心；卡在诚意层就诚实问自己愿不愿付成本，不愿就别硬撑；卡在正心层就先处理情绪再谈执行；卡在修身层就拆成最小日课。**只补当前最底层那个断点，不跨层空想。**
6. **入静虑（求周全）**：心定之后再开始"虑"——把这件事拆成可执行的先后步骤，每步验证通过再走下一步，而不是一口气想完美全局。
7. **絜矩量人（待人校准）**：凡涉及他人（队友、家人、上级），过一遍絜矩——我现在打算怎么对他？换成我被这样对待，我恶不恶？恶就换方式，把"我希望别人怎么对我"反推成"我该怎么对人"。
8. **验得（取策）**：走完一圈，确认"得"——是否拿到了一个清晰、可执行、不漂移、待人有度的下一步？没有则回到第①步重新止定，而非带着乱局硬冲。

## 五、约束边界

1. 「次第」不是拖延的借口：补底层不等于无限期准备，每一层都要有一个"打通的验收标准"，达标即进，不许永远停在"格物调研"。
2. 「知止」不是保守求稳：止是定边界、知终点、止于至善，不是止步不前；边界之内要全力做到。
3. 次第检验只用于自我定位与补漏，不用于苛责自己或贬低他人——别人跳层做成了，不代表你也能跳，各人根基不同。
4. 「壹是修身为本」是回归自我改进，不是把一切外部问题都内归因成"我不够好"——客观条件（资源、运气、环境）确实存在，该争外部资源时也要争；修身为本 ≠ 凡事都是我的错。
5. 絜矩之道是待人的互惠尺，不是"老好人妥协术"：推己及人推的是"分寸与公平"，不是放弃原则去讨好；底线问题不适用絜矩折中。
6. 紧急事故（安全、健康、突发危机）不走完整八步——先止损，事后再用本 skill 复盘定止。

## 六、案例示例

**案例一（独立开发·越级求成与定止）**：想做一个游戏 / 工具，一上来就想搞完整功能、漂亮界面，做了三个月没出一个能跑的版本，越做越焦虑。
- 背景：直接跳到"修身 / 成果"层，跳过了格物（该做什么最小可用版）与诚意（愿不愿为最小版熬），还在三纲领上误把"平天下（做大作）"当起点，没先"明明德"（自己会不会这门手艺）。
- 走逻辑链：先止——把终点收敛成"两周内一个能跑、能玩的最小 Demo"；再定——砍掉剧情、皮肤、联机等一切指向 Demo 之外的念头；归三纲——当前只配站在"明明德"层（先把手艺练到能出 Demo），不贪"亲民 / 大作"；次第检验——卡在格物层（没分清 MVP 是什么）；补卡层——回去调研同类产品的最小可玩点；入静虑——拆成"第1天出主循环、第3天出核心交互、第7天出可玩闭环"；验得——两周后拿到一个真能跑的 Demo，而非半成品幻想。
- 结论：越级求成时，退回最底层断点补一层，比硬冲快十倍。

**案例二（人生抉择·临事慌乱）**：同时面对考试、求职、竞赛多线压力，deadline 叠在一起，每天醒来就慌，什么都做不进去。
- 背景：念头泛滥、心乱无定，"虑"不出来。
- 走逻辑链：先止——写下未来两周唯一的"止"：先保哪一件（如考试）为核心目标；再定——其余事情标注"顺延 / 最低限度维持"；归三纲——此刻只需"明明德"这一件事站住，其余都是干扰；次第检验——卡在正心层（心态慌乱，事想不下去）；补卡层——先做一次静下来的视角梳理（对应帝御「温」），不压抑压力而先让心安；入静虑——心安后把考试拆成每日最小复习块；验得——每天只执行那一块，两周后核心项落地。
- 结论：临事慌乱时，先止后定再静安，顺序错一步都白搭。

**案例三（率土 / RoboCon 带队·絜矩之道收心）**：当了团长 / 队长，对下催进度催得极狠，动不动公开点名，结果老队员消极、新人不敢说话；可你自己当年最讨厌的，正是那种只催进度、不听解释的上级。
- 背景：只讲"齐家 / 治国平天下"（要队伍出成果），没修到自己的待人之尺——絜矩歪了，己所不欲偏施于人。
- 走逻辑链：先止——定"本周先要队伍心气回正"这个止点，而非先要战果；再定——暂停一切公开点名；归三纲——先"明明德"（自己作为带头人先摆正待人方式）再谈亲民（带队伍）；次第检验——卡在正心 / 修身层（自己急躁）；补卡层——把公开催改成一对一沟通；絜矩量人——把"我不想被上级怎样"列出来，逐条反推"我该怎样对队员"（如：我不想被当众下不来台→就私下沟通）；验得——一周后队伍说话的人多了，进度反而稳了。
- 结论：絜矩之道不是和稀泥，是把"我希望被怎样对待"当尺子量自己的待人动作——你怎么被对待过，就是你待人的参照系。

## 七、与帝御体系联动

- **归层**：心法层为主，兼御势层。主导诀「温」（静而能安——止定静安即煅渊御极的落地路径），辅以「明知琢道」（次第——格致诚正修齐治平即识践知旋的纵向展开，从格物到平天下是一条完整的认知—实践链），再以「御势·统御」承接「絜矩之道」（推己及人、齐家治国的待人尺度）。
- **诀系**：温（止定静安）+ 明知琢道（识践知旋·次第）+ 俭（先本后末、收束泛滥念头）+ 恭（絜矩——宏观定团队边界、微观量每个队员的处境）。
- **与基础诀的根系联系（依 E05）**：「止定静安」即「温」的操作化——温是煅渊御万极，其入口正是"先止后定、静定安虑"，心不先止于一处，渊煅不成；「八条目」即「识践知旋」的纵向版——格物致知是"识"，诚意正心修身是"践中之心法"，齐家治国平天下是"知而后行"的外展；「絜矩」是「恭」的待人面——恭者扶宏察微，于待人上即是先量自己的分寸（微）、再定对队伍的尺度（宏）。
- **调度方式**：帝御定位处境为"目标漂移 / 想法泛滥 / 越级求成 / 临事慌乱 / 待人双标失度"的情形时，经万法归宗索引触发本子技能，独立加载并按「推演逻辑链」执行；与主文件分工——主文件给"温"与"识践知旋"的定性框架及"次第检验"口径，本文件给《大学》的完整三纲领—八条目—六步定止—絜矩待人操作法；与《中庸》分工——大学重"次第与定止"（往哪停、按什么顺序走），中庸重"动态取中"（两极之间怎么平衡），二者合看：大学定"止"，中庸定"中"。
