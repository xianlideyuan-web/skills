# 《大学》· 帝御子技能

## 一、典籍定位

《大学》是帝御内炼之经中的"次第与定止学"：它不教你想得多大，而教你按什么顺序一步步做、在哪一步先停住。格致诚正修齐治平是一条不可颠倒的链条，止定静安虑得是一套临事不乱的操作流。适用于想法泛滥、目标漂移、越级求成、临事慌乱的时刻——是把"温"的煅渊路径落成"先停哪一步、再补哪一层"的工具书。

## 二、核心公理

- **次第不可躐等**：「物格而后知至，知至而后意诚，意诚而后心正，心正而后身修，身修而后家齐。」（经一章）帝御化：从认知到行为是有严格先后的链条——格物（看清事实）→致知（摸到规律）→诚意（真心想做）→正心（摆平心态）→修身（落到行为）。上一层没打通，直接跳到下一层，就是"越级求成"，必然返工。落判断：你现在急着做的事，上一层（看清了吗？真想做吗？心平了吗）真的通了吗？
- **知止为万端之始**：「知止而后有定，定而后能静，静而后能安，安而后能虑，虑而后能得。」（经一章）帝御化：一切混乱的源头是"不知道止在哪"。先定目标的边界与终点（止），心才会定；定了才静得下来；静得下来才安身；安身之后才虑得周全；虑周全了才有所得。落动作：乱的时候，第一步永远不是"做什么"，而是"止于何处"——把目标边界写下来。
- **壹是皆以修身为本**：「自天子以至于庶人，壹是皆以修身为本。」（经一章）帝御化：外部事务（齐家/项目/关系）的一切问题，根子都在自己这一层没修好。事情做不顺时，别急着改外部，先回到"我自己这层哪里没到位"——认知、意愿、心态、行为，哪层虚补哪层。落判断：此刻让你痛苦的，是外部条件不够，还是自己这一层的地基没打牢？
- **诚意毋自欺**：「所谓诚其意者，毋自欺也。」（传六章）帝御化：别骗自己"我很想做"——嘴上想做、身体很诚实地拖延，就是意不诚。诚意层的检验标准：愿不愿意为它付出真实成本（时间、钱、面子、苦）。不想付成本的"想"，是自欺。
- **先本后末**：「此谓知本，此谓知之至也。」（经一章）帝御化：万事都有本末先后——本在前，末在后。分清哪是根（必须先做）、哪是枝叶（可以后做），把力气先砸在本上。本立而道生。

## 三、适用场景清单

1. 目标漂移：同时想要太多、三心二意，做着做着忘了当初要什么。
2. 想法泛滥：脑子里念头一个接一个，越想越乱，无从下手。
3. 越级求成：基本功没打就想做高阶成果，天天急于求成、频繁返工。
4. 临事慌乱：deadline 逼近或突发变故，心乱如麻，越急越做错。
5. 想一步登天：看到别人成果就想跳过积累直接复制，不肯做底层。
6. 长期项目卡壳：做了很久没进展，不知道该从哪一层下手补。

## 四、推演逻辑链

1. **先止（定边界）**：拿出一张纸，写清这件事的"止"在哪——终点是什么、边界到哪为止、什么算"成了"。一句话说不清楚，说明目标本身还模糊，先别动手。
2. **再定（不漂移）**：对照这个边界，把当前所有正在做/想做的事过一遍——凡是不指向这个终点的，一律划入"暂停清单"，防止目标被新念头带跑。
3. **走次第检验（定位卡点）**：按链条逐层自评，找出第一个"没打通"的环节——①格物：事实看清了吗？②致知：背后规律摸到了吗？③诚意：真心想做、愿付成本吗？④正心：心态摆正、不躁不馁吗？⑤修身：每天的具体行动跟上了吗？
4. **补卡层（不跨层）**：卡在格致层就回去补认知/调研，不要空喊决心；卡在诚意层就诚实问自己愿不愿付成本，不愿就别硬撑；卡在正心层就先处理情绪再谈执行；卡在修身层就拆成最小日课。**只补当前最底层那个断点，不跨层空想。**
5. **入静虑（求周全）**：心定之后再开始"虑"——把这件事拆成可执行的先后步骤，每步验证通过再走下一步，而不是一口气想完美全局。
6. **验得（取策）**：走完一圈，确认"得"——是否拿到了一个清晰、可执行、不漂移的下一步？没有则回到第①步重新止定，而非带着乱局硬冲。

## 五、约束边界

1. 「次第」不是拖延的借口：补底层不等于无限期准备，每一层都要有一个"打通的验收标准"，达标即进，不许永远停在"格物调研"。
2. 「知止」不是保守求稳：止是定边界、知终点，不是止步不前；边界之内要全力做到。
3. 次第检验只用于自我定位与补漏，不用于苛责自己或贬低他人——别人跳层做成了，不代表你也能跳，各人根基不同。
4. 「壹是修身为本」是回归自我改进，不是把一切外部问题都内归因成"我不够好"——客观条件（资源、运气、环境）确实存在，该争外部资源时也要争。
5. 紧急事故（安全、健康、突发危机）不走完整六步——先止损，事后再用本skill复盘定止。

## 六、案例示例

**案例一（独立开发·越级求成与定止）**：想做一个游戏/工具，一上来就想搞完整功能、漂亮界面，做了三个月没出一个能跑的版本，越做越焦虑。
- 背景：直接跳到"修身/成果"层，跳过了格物（该做什么最小可用版）与诚意（愿不愿为最小版熬）。
- 走逻辑链：先止——把终点收敛成"两周内一个能跑、能玩的最小Demo"；再定——砍掉剧情、皮肤、联机等一切指向Demo之外的念头；次第检验——卡在格物层（没分清MVP是什么）；补卡层——回去调研同类产品的最小可玩点；入静虑——拆成"第1天出主循环、第3天出核心交互、第7天出可玩闭环"；验得——两周后拿到一个真能跑的Demo，而非半成品幻想。
- 结论：越级求成时，退回最底层断点补一层，比硬冲快十倍。

**案例二（人生抉择·临事慌乱）**：同时面对考试、求职、竞赛多线压力，deadline 叠在一起，每天醒来就慌，什么都做不进去。
- 背景：念头泛滥、心乱无定，"虑"不出来。
- 走逻辑链：先止——写下未来两周唯一的"止"：先保哪一件（如考试）为核心目标；再定——其余事情标注"顺延/最低限度维持"；次第检验——卡在正心层（心态慌乱，事想不下去）；补卡层——先做一次静下来的视角梳理（对应「温」），不压抑压力而先让心安；入静虑——心安后把考试拆成每日最小复习块；验得——每天只执行那一块，两周后核心项落地。
- 结论：临事慌乱时，先止后定再静安，顺序错一步都白搭。

## 七、与帝御体系联动

- **归层**：心法层为主。主导诀「温」（静而能安——止定静安即煅渊御极的落地路径），辅以「明知琢道」（次第——格致诚正修即识践知旋的纵向展开）。
- **诀系**：温 + 明知琢道（识践知旋）+ 俭（先本后末、收束泛滥念头）。
- **调度方式**：帝御定位处境为"目标漂移/想法泛滥/越级求成/临事慌乱"的内修情形时，经万法归宗索引触发本子技能，独立加载并按「推演逻辑链」执行；与主文件分工——主文件给"温"与"识践知旋"的定性框架及"次第检验"口径，本文件给《大学》的完整六步定止与补层操作法。
