# 《止学》· 帝御子技能

## 一、典籍定位

《止学》是一部专讲"何时该停"的**传世文本**（旧题隋·王通文中子作，学界多认为系后世托名辑成；本技能**取其理而不泥其伪**——只取它"知止"的道理，不纠结真伪、不冒充确证原文）。它是帝御内炼之经里的**"刹车系统"**：别家经典多教你怎么进，它专教你**怎么在对的时刻停下来，把已经到手的守住、把下一轮的势能蓄住**。

传世本分十卷（篇名依传世文本）：**智卷、势卷、利卷、辩卷、誉卷、情卷、蹇卷、释怨卷、心卷、修身卷**——十卷所止各有侧重。帝御只取其理，把十卷收束为一套通用刹车法，并附速查表以便定位"此刻是哪一摊在冒头"：

| 卷 | 所戒（该止之处） | 帝御落点 |
|---|---|---|
| 智卷 | 戒"逞谋"——聪明、算计不该用尽 | 再算一步不如收手，智有穷而道无尽 |
| 势卷 | 戒"恋权"——势到极处不处 | 势盛时先留退路，不处其极 |
| 利卷 | 戒"贪多"——利不求满 | 利尽处即止，落袋为安 |
| 辩卷 | 戒"争胜"——辩不必尽胜 | 赢了嘴、输了人，知止不争 |
| 誉卷 | 戒"邀名"——名盛反忌 | 名盛时不追加码，免得名反噬 |
| 情卷 | 戒"沉溺"——深情反伤神 | 情深处抽身，尽心后不纠缠 |
| 蹇卷 | 戒"怨尤"——困厄时不怨天尤人 | 低谷止怨，先养本再图后 |
| 释怨卷 | 戒"结怨"——小怨早释 | 小怨不赦则大怨生，及时翻篇 |
| 心卷 | 戒"无归"——心要有个止处 | 止者心之至，心安住手才停 |
| 修身卷 | 戒"自满"——修到高处不骄 | 知止不骄，长保其身 |

帝御用法：先把最上头那桩事对号入座到某一卷，再按本技能"推演逻辑链"走刹车流程。

适用于贪进不止、名利盛时不知收、all in 前、被欲望裹挟的场合，是把"俭、让、守"落到"什么时候收手"的操作手册。

## 二、核心公理

- **大智知止，小智惟谋**：「大智知止，小智惟谋；智有穷而道无尽哉。」（智卷，传世文本）帝御化：**最高的聪明不是会"谋进"，是知道何时"停下"；小聪明天天算计怎么再多拿一点，大智慧算的是什么时候该收**。落判断：此刻你脑子里转的是"再怎么多拿一点"还是"该收手了"？满脑子都是前者，正是"小智"模式——立刻警惕。智慧是有穷尽的，而欲望 / 局势无尽，靠无限谋划赢不了无限的局，只能靠"止"截断它。
- **止者，心之至也（止是心的归处，不是行为的终点）**：「止者，心之至也。」（心卷，传世文本转述其义）帝御化："止"首先是**心有个归处**——心不被欲望牵着乱跑，知道自己安在哪个边界上，行为上的"停"才立得住。心若无止，嘴上说停、手还在加仓。落判断：我此刻的"想停"，是心里真有个安处（知道够了），还是只是被吓了一下、等回过神又想进？前者是真知止，后者是假收手。
- **知止不殆，不止招损**：（传世文本转述）利没有穷尽之处，欲没有满足之时；不知止者，眼前赚的会在"该止未止"时连本带利折回去。帝御化：**祸患极少来自"停早了"，多来自"该停没停"**。落判断：把"继续进"的最坏回撤算一遍——是只少赚一点，还是会把本金 / 声誉 / 健康赔进去？后者就该止。
- **止于当止，四盏红灯**：（传世文本转述其义）何时该止？四处为灯——**利尽处**（收益已到边际递减还在加仓）、**名盛时**（夸赞、热度、顺境到顶还想再要）、**力竭前**（身体、资金、情绪见底还硬撑）、**情深处**（投入一段关系 / 一桩事过深、沉溺到伤神还拔不出来）。四灯任一亮起，即到止点。落动作：把这四盏灯做成自己的检查清单，每加仓、每加码、每沉陷前先过一遍。
- **止而后进，止是蓄势不是躺平**：（传世文本转述）止不是认输趴下，是踩一脚刹车——为了过弯之后再加速。帝御化：把"止"写成**"暂停清单"而非"放弃清单"**：这次停，是为了下一轮更稳地进；止后转入帝御「凝」（复盘、休整、养本），而不是从此躺平。落判断：我此刻的"止"，是停下来养本等下一轮，还是逃避该担的事？前者是知止，后者是退缩。
- **十卷所止，各戒一端（框架）**：（传世十卷总括）智戒逞谋、势戒恋权、利戒贪多、辩戒争胜、誉戒邀名、情戒沉溺、蹇戒怨尤、释怨戒结怨、心戒无归、修身戒自满——**你在哪一摊贪进，就对应哪一卷该止**。帝御化：先定位自己此刻是"哪一摊在冒头"——是贪利（利卷）、恋名（誉卷）、还是沉溺情（情卷）、逞强谋（智卷）？定了卷，才知道该收的是哪一味。落动作：把最近三个月最上头的那桩事归到十卷中的一卷，对症下药。

## 三、适用场景清单

1. 贪进不止：已经连赢 / 连赚，却满脑子"再来一把更大的"。
2. 名利盛时不知收：风头正劲、夸赞满屏，想继续加码到顶。
3. all in 前：准备押上全部本金 / 时间 / 前途赌一把，需要先踩刹车。
4. 被欲望裹挟：同时开好几摊还想再加一摊，说不清是真需要还是贪。
5. 身体 / 情绪透支：熬夜连轴、情绪见底还硬撑着不停。
6. 沉溺太深：对一段关系 / 一桩投入陷得太深，明知道该抽身却拔不出（情深处）。
7. 争名争胜上头：为了一口气、一个称号、一场嘴赢，不惜耗钱耗神耗关系（誉卷 / 辩卷）。
8. 决策后复盘：上次是不是"该止没止"把赚的亏回去了，需要回看止点设对没有。

## 四、推演逻辑链

1. **查欲归卷**：把此刻驱动自己"再进一步"的那股劲写下来——它到底是真实需要，还是"别人有我也要""再来一把就收手"的贪？并把它归到十卷中的某一卷（利 / 誉 / 情 / 势……），定准该收的是哪一味。
2. **对四灯**：逐条对照四盏红灯——利是否已到边际递减（利尽处）？名 / 誉 / 热度是否已到峰值（名盛时）？身 / 资 / 情绪是否将竭（力竭前）？是否沉溺到伤神（情深处）？亮几盏记几盏。
3. **算回撤**：若此刻不止，最坏情形回撤是多少？现有的本金、声誉、身体、关系扛不扛得住这个回撤？扛不住，直接进第 4 步。
4. **事前定止点**：**在还没被欲望裹挟时**就写下"止点"——赚到 X、做到 Y、热度到 Z、沉溺到 W 就停，写成可观察的数字 / 事件，不靠临场感觉（临场感觉必被欲望篡改）。
5. **到点即止**：信号一到，按事先写好的止点执行，不因"再等等还能更多"改规则；把止的动作仪式化（落袋、官宣、下线、停手、拉黑 / 退群），让"止"真实发生。
6. **止后蓄势**：止完转入帝御「凝」——复盘、休整、养本（补身体、补现金流、补状态、梳理情），为下一轮进蓄力；明确这是暂停不是终局，防止"止"滑成"躺平"。
7. **心归其止**：事后自检——这次收手，心真的安在"够了"上了吗？还是表面停了、心里还在痒？心未止，补一次"止者心之至"的静处（对应帝御「温」），把心安住。

## 五、约束边界

1. **知止不是逃避责任的借口**：该担的底线责任（健康红线、债务、考试、承诺）不能用"知止"为名逃——止的是"贪进"，不是"该做的事"。
2. **止点必须事前定**：不能事后悔到了才说"早该止"——临场感觉必然被欲望篡改，止点要在清醒时写死。
3. 不拿"知止"给自己的怂找理由：窗口真在、胜算在手、四盏灯一盏未亮时的"止"是保守，不是智慧；四灯未亮不算止。
4. **此书为托名传世文本，引文审慎**：凡无法确证的句子皆作转述，不冒充原文、不伪造"文中子曰"；取其理不泥其伪。
5. 止是为了再进，不是终点哲学：别把"知止"活成"什么都不做"的虚无——止而后能进，才是它的本意。
6. 情深处之止 ≠ 绝情绝义：止的是"沉溺到伤神"，不是该尽的责任 / 该守的关系；对人对事尽心之后的抽身，才叫止，不是半道甩锅。

## 六、案例示例

**案例一（个人财务 · 连胜后加注）**：一轮操作浮盈 50%，手感极顺，身边人都在夸，想把存款全加进去"乘胜追击"。
- 背景：两盏灯已亮——名盛时（连赚心态飘、被夸上头）＋利尽处（再追高边际收益递减、回撤风险陡增）。归卷：利卷 + 誉卷。
- 走逻辑链：查欲归卷——写下驱动自己的是"真趋势"还是"再来一把就收手"的赌性，归利卷；对四灯——两灯亮；算回撤——全押后若回撤 30%，本金会伤到安全垫，扛不住；事前定止点——清醒时写死"浮盈落袋一半、剩余部分回撤 10% 即清"；到点即止——按纪律落袋，不因"再等等能更多"改规则；止后蓄势——复盘这轮为什么成，养本等下一轮窗口；心归其止——落袋后不再盯盘心痒。
- 结论：大智知止——赚到手的才算钱，浮盈不加注，把"知止"写在操作纪律里，不交给临场心态。

**案例二（对局 / 比赛与人生抉择 · 力竭前止损）**：连胜一晚上手感正好，想通宵再冲几颗星 / 赶完一个大活；同时还兼着三摊事，想再加第四摊。
- 走逻辑链：查欲归卷——归势卷 / 利卷（贪多求胜）；对四灯——力竭前（身体已透支、反应开始慢）＋利尽处（同时四摊每摊都喂不饱）；算回撤——通宵硬撑，下半夜必失误连跪，把今晚连胜的分掉回去，第二天还废一天；事前定止点——"连赢三局后到点即下"或"三摊封顶"；到点即止——按时下线 / 砍掉第四摊；止后蓄势——睡够、收心，第二天状态在线再战。
- 结论：连胜时最容易"利令智昏"，四盏红灯里"力竭前"这盏最隐蔽也最致命——身体亮红灯，就是止点。

**案例三（情深处 / 誉卷 · 沉溺与争名之止）**：在一段投入很深的关系 / 一个被夸上天的项目里，明知已经不对等、不对路，却舍不得抽身；或是为了保住一个"大神 / 团长"的名声，硬撑着接超出能力的活。
- 背景：两盏灯——情深处（投入过深、沉没成本绑住）＋名盛时（被称号架住下不来）。归卷：情卷 + 誉卷。
- 走逻辑链：查欲归卷——写下"舍不得"到底是真在乎，还是不甘心沉没成本、怕丢面子；对四灯——情深处 + 名盛时两灯亮；算回撤——继续撑下去，赔进去的是时间、健康和还能重来的本钱；事前定止点——定一个可观察的抽身信号（如"再沟通一次仍无改变即止""这个季度后不再接同类活"），不靠"再等等看"；到点即止——信号一到就执行（摊牌 / 交棒 / 官宣淡出），把止的动作做真实；止后蓄势——把原投进去的心力收回，投到新方向上；心归其止——事后自检"是不是还在反复想那个人 / 那个称号"，心未归就再静处一次。
- 结论：情与名是最隐蔽的两盏灯——它们不亏钱，却最耗神；能在"情深处"和"名盛时"抽身，才是大智知止里最难也最值的那一刀。

## 七、与帝御体系联动

- **归层**：内炼之经。以**心法层**为主——「俭」（积微累势、止欲节耗，圣必困俭）＋「让」（让而无让：让出眼前再多拿的利，蓄后续更大的势）＋「温」（静下来，不被欲望劫持情绪）；辅以**主见层·独见守己（守）**——不被"再赢一把""别人都赚了"的剧本裹挟，人生节奏由自己说了算。
- **诀系**：俭（止欲）+ 让（让利蓄势）+ 温（静而不躁、心归其止）+ 独见守己之守（守得住手）。
- **与基础诀的根系联系（依 E05）**：「止者心之至也」即「温」之静——心有所止、不随欲跑，正是温所煅的渊心；「大智知止」即「俭」——积微累势、困俭节耗，于盛时知收；「让而无让」即让出眼前之利、蓄后续之势；「知止不殆」是「独见守己·守」在欲望面前的硬约束。
- **调度方式**：帝御定位处境为"贪进 / 名利盛时不知收 / all in 前 / 被欲望裹挟 / 沉溺太深"时，经万法归宗·内炼之经索引触发本子技能，独立加载并按「推演逻辑链」执行；与主文件分工——主文件给"俭、让、守"的定性纲领，本文件给《止学》四灯检查、事前定止点、到点即止、心归其止的完整刹车操作法；与《道德经》分工——老子"知足不辱"是心法总论，止学把它落成"利尽处 / 名盛时 / 力竭前 / 情深处"四个可执行的刹车点；与《素书》分工——素书"吉莫吉于知足"偏修身立人，止学偏贪进临场刹车，二者互参。
