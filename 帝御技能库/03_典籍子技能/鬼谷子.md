# 《鬼谷子》· 帝御子技能

## 一、典籍定位

《鬼谷子》传世十三篇，是一部极冷静的"人心观察与沟通操作手册"。它不教你讲义气，也不教你耍阴谋——它教的是一套安静的工作方法：**开口之前先看，倾听之中再判，从细节、情绪、重复出现的词里，读出对方真正要什么，再决定自己这一句该说还是该听。**

十三篇各有分工，本 skill 按"观察—验证—开口—决断—内修"的顺序重组其骨架：

- **捭阖**：开合之道。开口是捭、沉默是阖，是一切沟通的总开关。
- **反应**：反观覆验。用过去验现在、用对方的话反推其心。
- **内揵**：摸关系。先看清彼此内心的亲疏远近，再决定说辞能不能进去。
- **抵巇**：见微知著。缝隙刚有征兆时就补上，等裂大了再救就晚了。
- **飞箝**：钩真情。用诱导性的话让对方把真意露出来，再抓住它。
- **忤合**：背向之度。跟谁、不跟谁，没有永远的贵人，只有当下合不合。
- **揣**：量权揣情。在对方情绪极值时，读出他压不住的欲望与恐惧。
- **摩**：摩意。揣的下一步——试探一下，看对方的真实反应是否与你猜的吻合。
- **权、谋**：权衡说辞、谋定后动。「谋之于阴，故曰神；成之于阳，故曰明。」（谋）帝御化：重要方案先在暗中把双方诉求、代价、底线算透，不要提前亮底牌、打草惊蛇；事成后对方才明白你早算到了。
- **决**：决情定疑。信息到了该拍板时，不能拖。
- **符言**：主事者要耳聪目心明——「目贵明，耳贵聪，心贵智。」（符言）帝御化：看清（明）、听全（聪）、想透（智）是观察人的三件套；信息不全时不急着下结论。
- **本经阴符七术**：内修七法——盛神、养志、实意（修内心），分威、散势（分发威势、因势而动），转圆（计谋如圆转无穷、随机应变），损兑（临事权衡、当损则损）；核心是观察他人之前先修自己的内功。

**一句话定位**：它的价值不在纵横捭阖的算计，而在把「恭（察微）」落到"这一句话该说还是该听"的操作上——先读懂人，再开口；读懂之后，找的是双赢的交叉点，不是拿捏对方的软肋。

**边界先立**：重在洞察以达成合作，绝不用于操控人心、PUA、情感操纵、商业洗脑、精神控制。揣摩是"理解对方"的工具，不是"摆布对方"的武器。

## 二、核心公理

- **捭阖——先阖听察微，再捭说动人**：「捭阖者，天地之道。捭阖者，以变动阴阳，四时开闭，以化万物。」又：「捭之者，开也，言也，阳也；阖之者，闭也，默也，阴也。」（捭阖）帝御化：开口是"捭"，沉默是"阖"，两者不是口才与性格，而是工具——该开不开，信息给不出去；该阖乱开，底牌全漏。多数人搞反了：想知道对方要什么，却一直自己说。落判断：此刻我的目标是"让对方多暴露"，还是"让对方多接受"？要前者就阖（听），要后者才捭（说）。顺序上永远先阖后捭——先听明白，再开口。

- **反应——反以观往，覆以验来；自知而后知人**：「反以观往，覆以验来；反以知古，覆以知今。」又：「知之始己，自知而后知人也。」（反应）帝御化：读人有两条路——一是用他过去说过、做过的事，反过来验他现在的心；二是先拿自己当尺子。自己的秤不亮（我此刻想要什么、怕什么、底线在哪），就会把自己的欲望投射到对方身上，误读成"他也想要这个"。落动作：每次谈判/沟通前先写三行：我要什么、我让什么、我怕什么；写完再开口，也再去读对方。

- **揣摩——揣情于情绪极值，摩之以验内符**：「揣情者，必以其甚喜之时往而极其欲也，其有欲也，不能隐其情；必以其甚惧之时往而极其恶也，其有恶也，不能隐其情。」（揣）又：「摩者，揣之术也；内符者，揣之主也。」（摩）帝御化：人在平静时戴面具，在大喜、大惧、大急时防线最松。想知道对方真实底线，不要在他冷静讲道理时逼问，要在他对某事明显兴奋或明显焦虑时顺势深问；问完再"摩"一下——轻轻试探，看他的反应是否和你猜的吻合。那一刻说漏的、被试探验证的，才是真的。落动作：把对方这一场对话里重复出现、情绪起伏的词记下来，那是他的"志意"所在，也是合作的真正接口。

- **抵巇——缝隙初有朕兆，见微知著、及时补救**：「巇始有朕，可抵而塞，可抵而却，可抵而息，可抵而匿，可抵而得。」（抵巇）帝御化：裂痕刚冒出一点苗头（朕）时，可以补上、可以劝退、可以息事；等它裂成大缝，就只能由别人"抵而得之"（趁虚夺权）。落动作：关系、项目、合作里，第一次出现"话没说开、小误会、某人突然沉默"时，当场就处理，别拖——小裂缝是最便宜的修复窗口，拖成大分裂就是最贵的清算。

- **飞箝——以钩辞引出真情，再抓住它**：「引钩箝之辞，飞而箝之。」（飞箝）帝御化："飞"是先用话让对方兴奋、放松、多说；"箝"是顺势把他露出来的真意抓住。这不是诈术，而是沟通技巧——用开放式、抬举式、共情式的话（"听起来这件事对您特别重要"），让对方把立场背后的真实顾虑倒出来。落动作：想要信息，别盘问，用一句"钩"——把球抛回去、把他的情绪点出来，他自己会接下去。

- **忤合与决断——世无常贵，决情定疑**：「世无常贵，事无常师。」（忤合）又：「决情定疑，万事之机。」（决）帝御化：没有永远正确的追随者，也没有永远该跟的人；合则留、不合则去，标准是当下双方诉求合不合。而信息一旦足够，就要敢拍板——「决情定疑」，犹豫本身在消耗机会。落动作：摸清对方真实诉求后，该合作就主动亮合作点（捭），该分就体面地分（忤合）；最怕的是反复试探、迟迟不决，把对方的耐心磨没。

- **本经阴符——盛神养志实意，先修己再观人**：本经阴符七术为内修之纲：「盛神中有五气，神为之长，心为之舍，德为之大。」（盛神法五龙）「养志则心不扰。」（养志法灵龟）「实意者，气之虑也。」（实意法腾蛇）帝御化：鬼谷子比谁都清楚——观人的内功，不在嘴，在心。神要足（精力充沛、心神不散）、志要定（不被外物撩拨得心神不宁）、意要实（思虑扎实、不浮）。自己心浮气躁、欲望遮眼时，读人必带偏见。落动作：沟通前先让自己静三分钟——神不盛不进入重要谈话，志不定不做大判断。

## 三、适用场景清单

1. **谈判**：谈合作、谈薪、谈价、谈分工，需要摸清对方真实底线与诉求。
2. **识人**：新认识的合作方、队友、朋友，需要快速判断其真实关切与为人。
3. **沟通协作**：意见谈不拢、双方各说各话，需要找到真正的分歧点（内揵：先看关系亲疏）。
4. **被说服前**：对方在说服你，你需要先听明白他到底要什么，再决定接不接。
5. **化解冲突与补缝**：关系紧张、对话僵住、刚出现小误会，需要在"巇始有朕"时及时修补。
6. **面试/被面试**：需要读懂面试官真正考察的点，或候选人真正在意的条件。
7. **该合作还是该散伙**：一段合作/关系要不要继续，需要在"忤合"处做决断，而不是无限耗着。

## 四、推演逻辑链

1. **先知己（反应）**：开口前用三行纸盘自己——我此来要的核心结果是什么、可让步的是什么、绝不能丢的是什么。定了自己的秤，才不会误读对方。
2. **修内功（本经阴符）**：重要谈话前让自己静三分钟，神足、志定、意实；心浮气躁则推迟或先稳住再进入。
3. **观局外、摸亲疏（内揵）**：不急着进入正题，先观察环境与对方状态——他今天急不急、累不累、和我的关系亲到哪一步。关系没到，再对的说辞也进不去。
4. **阖而听（第一步沉默）**：先请对方多说，自己少表态。用开放式提问（"你这边最在意的是什么"）替代封闭判断，让他把立场、抱怨、期待倒出来。
5. **察微抓志意（飞箝+揣）**：边听边标记——他重复最多的词、突然加重语气的点、提到时眼睛发亮或明显防御的话题；在他情绪有波动的间隙顺势追问验证。这些"嗜欲与虚实"就是他的真实诉求。
6. **摩意验证**：轻轻试探一下（"听起来这一点对你特别重要，是因为……？"），看对方反应是否与猜测吻合；吻合则真，错位则回到第4步继续听。
7. **抵巇补缝**：若过程中发现已有小误会、小裂痕，当场就地处理，不让它过夜变大。
8. **决捭阖、定忤合**：摸准后决定自己的开口策略——诉求与我方交集大，就主动亮合作点（捭）；分歧还在暗处，就继续以提问换信息（阖）；实在不合，就体面分途（忤合）；信息够了就拍板，不拖。

## 五、约束边界

1. **重在洞察以达成合作，绝不用于操控人心、PUA、情感操纵、商业洗脑、精神控制**——揣摩是"理解对方"的工具，不是"摆布对方"的武器；凡以诱导对方违背其真实利益为目的的用法，一律禁止。
2. 洞察≠算计：读懂对方诉求后，正确用法是"找到双赢点"，错误用法是"利用其软肋拿捏"。前者促成长期合作，后者只换来一次性的信任破产。
3. 揣情于情绪极值，是观察而非诱供：不得故意制造对方的恐惧、焦虑或狂喜来套话；只在对方自然出现的情绪窗口里顺势了解。
4. 对亲友日常相处不启用"揣摩模式"：亲密关系靠真诚与袒露，不靠洞察与试探；把这一套带回家，会杀死信任。
5. 自知始终先于知人：若自己情绪上头、欲望遮眼、神不盛志不定，先回到第1、2步把自己稳住，此时读人必带偏见。
6. 抵巇是补缝不是钻缝："可抵而塞"是去修补关系，不是去利用裂痕搞破坏；把见微知著用成挑拨离间，违背本 skill 的合作宗旨。

## 六、案例示例

**案例一（谈判协作·找交叉点）**：接一个外包项目，甲方反复强调"预算有限"，方案却一直加功能。
- 背景：按表面立场谈，永远在砍价里耗死。
- 走逻辑链：先知己——我要合理报价+可控工期，可让步界面细节，不能丢工期底线；观局外——甲方今天其实赶时间；阖而听——不急着报价，请他说清项目要解决什么业务问题；察微——他三次提到"老板下季度要拿它汇报"，对"什么时候上线"远比对"界面多炫"敏感；摩意验证——顺势问"您这边最紧的其实是上线时间对吗？"对方明显松口；决捭阖——不再堆功能让步，改提"核心功能按季度节点上线、炫酷界面二期再做"。
- 结论：成交价比原方案低20%，工期却保住了，双方真实诉求都落了地。

**案例二（团队沟通·读懂沉默与补缝）**：组队做比赛项目，一名老队员突然不怎么发言，进度还在推，但气氛不对。
- 背景：表面无事，凭"他没反对"当作一致——这正是一道刚开始的"巇"。
- 走逻辑链：观局外——他这两次会议明显话少、眼神避开争论点；内揵——公开群里追问只会让他更防御，改为私下一对一；阖而听——请他慢慢说；察微——他提到"上次方案被推翻时没人通知我"，语气里有不被尊重感；摩意——问"你真正在意的是不是信息没同步、自己像被绕过去了？"；抵巇——当场就把"以后重要决策提前一对一同步"定下来，不让这道小缝拖成他彻底消极。
- 结论：他的诉求不是反对方案，是"被当作核心成员对待"；当场补缝后，他立刻恢复出力。

**案例三（该合该分·忤合决断）**：一个合作了很久的伙伴，几次分工都含糊、关键节点总掉链子，你想继续又怕再被拖。
- 背景：靠旧情维持，谁都不提"要不要继续"。
- 走逻辑链：先知己——我要的是可靠交付，情面不是核心诉求；阖而听——不指责，请他说自己那边的难处，听出他其实精力已不在这件事上；察微——他三次"最近忙"，志意已散；决忤合——「世无常贵，事无常师」，旧情不等于该继续绑在一起；拍板——体面地把后续拆成"轻合作"，不再绑定核心交付，双方都解脱。
- 结论：信息早够了，缺的只是"决情定疑"那一下；拖下去才是对双方最大的消耗。

## 七、与帝御体系联动

- **归层**：以「见（洞察）」为主导——清醒判断的前提是先把对方看明白；辅以心法层「恭（察微）」——扶宏察微，宏观上看合作全局，微观上盯每一句语气、每一个重复词。
- **诀系**：见（洞察）+ 恭（察微）+ 本经阴符（盛神养志实意＝内修静心）+ 独见守己之守（守住自己不被对方节奏带走）。
- **调度方式**：帝御定位处境为"谈判/识人/沟通协作/化解冲突/需理解对方真实诉求、判断一段合作该不该继续"时，经万法归宗·权衡之经索引触发本子技能，独立加载并按「推演逻辑链」执行；与主文件分工——主文件给「见」与「恭」的定性纲领，本文件给《鬼谷子》捭阖、反应、揣摩、抵巇、飞箝、忤合、决断、本经阴符的完整观察—开口—内修操作流程。
- **根系联系**：读人之术其根在五诀——温（先接纳对方真实诉求，不预设他该如何）、恭（察其微）、识（认识对方本来的志意，而非我投射的想象）、知（读出的判断经合作结果验证后再校准）。洞察是为了"御物·无不可用"地促成共赢，不是为了把人当成可摆弄的对象。
