# 《反经》· 帝御子技能

## 一、典籍定位

《反经》（唐·赵蕤撰，一名《长短经》）是帝御权衡之经里的"权变总枢"。它的书名即纲领——"反经"不是背叛经典，而是**当常经（通行打法）在时移事易后失效时，敢于偏离它、换一条仍合于大道的路**。它把三件事打通：什么时候该弃旧换新、人该怎么识怎么用、一堆意见来了该怎么从"众谋"走到"独断"。适用于打法失灵、用人分工、意见冲突需定夺的场合，是把"兵无常势"从一句口号落成一套换道流程的工具书。

## 二、核心公理

- **反经合道，不执一法**：书名取义于《孟子》「君子反经而已矣」——反经不是叛道，是常经失效后的权变（《反经·适变》主旨：时移则事异，事异则备变；同一治道不能刻舟求剑）。帝御化：**同一招连续用三次仍不达效，问题多半不在"用力不够"，而在"招本身已不适用"**。落判断：把你正在死磕的那条常规打法列出来，数它最近三次的效果——三次皆不达效，就判定常经已失效，停止"再加把劲"，转入换道。变的是打法，不变的是目标与底线，这才叫"合道"。
- **知人则哲，惟帝难之**：「知人则哲，惟帝难之。」（《尚书·皋陶谟》，《反经·知人》奉为知人之难的总纲）帝御化：连尧舜都觉得识人最难——所以**绝不能凭一面之词、一顿饭印象、一次表现就定人**。落动作：看人只看三处——长期（三个月以上一贯如何）、关键处（钱、权、责、利关头他怎么选）、动机（他这么做图什么）。这三处凑不齐，就给他"观察期"，不盖棺定论。
- **任长弃短，量才而使**：《反经·任长》论用人之要，举陈平用奇、韩信将兵之例（转述其旨）——人各有能有不能，善用人者用其长而略其短，无求全责备之人。帝御化：**没有"全能选手"，只有"放错位置的长项"**。落动作：给任何要用的人先写两栏——三项长、三项短；派任务时只把"长项对口"的环节交给他，他的短项用制度、流程或另一名队友补位，而不是逼他把短项练成第零长项。
- **谋贵众，断贵独**：《反经》承先秦"广采众谋、独断于己"之旨（可参《史记》「千人之诺诺，不如一士之谔谔」）。帝御化：**收集意见期必须把门敞开，拍板那一刻必须把门关上**。落判断：此刻我在哪个阶段？——还在收集，就鼓励异见、专挑唱反调的问；已经到点要拍板，就停止开会、闭门定夺。最忌反过来：收集期一言堂、拍板后还天天摇摆。

## 三、适用场景清单

1. 常规办法连续失效：老打法越用力越糟，需要判断是"再坚持"还是"换打法"。
2. 识人用人：招队友、分组、分工、托付核心环节，需要判断这人能不能用、放哪个位。
3. 多方建议冲突：两派甚至多派意见吵得不可开交，需要从"众谋"走到"独断"。
4. 对手/环境升级：版本更新、规则变化、对手打法换代，旧应对全面失灵。
5. 复盘用人失误：当初看好的人掉了链子，需要回看是"看错人"还是"放错位"。
6. 自己陷入路径依赖：明明结果不对，却只想"这条路我熟，再试一次"。

## 四、推演逻辑链

1. **验常经**：列出此刻正在死磕的那条"常规打法"，统计它最近三次的实际效果。若三次皆不达效——判定常经已失效，停止"再加把劲"；若偶有一次成、两次败——先查执行漏洞，别急着否定打法。
2. **辨时势**：定位失效根源到底是哪个变量变了——对手变了？规则/版本变了？资源/人手变了？还是自己执行走样？变量变了→必须换招；执行走样→修执行，别乱换道。
3. **广咨众谋**：围绕"还能怎么打"穷举 3-5 条**完全不同方向**的路线，刻意纳入一条与你直觉相反的意见（谔谔之言），专问反对者"你觉得该怎么办"。此阶段只收集、不裁决。
4. **量人配路**：盘点可用之人各自的长/短两栏，把每条路线匹配给"长项对口"的人；关键环节绝不让短项来扛，短项用机制或队友补。
5. **独断于己**：闭门，按"胜算 × 代价 × 可逆性"给路线排序，选定一条主线，写死下一步第一个动作。拍板之后进入执行期，不再开讨论会反复摇摆；事后复盘另算。
6. **设哨验变**：给新打法设一个可观察的"哨点"——多长时间内、出现什么信号才算成；信号到了再加码，不到就再变一次。权变是循环，不是一锤定音。

## 五、约束边界

1. **权变不是无原则的墙头草**：反经必须"合道"——变的是打法，不变的是目标、底线与信用；不能打着"权变"的旗号翻烧饼、朝令夕改。
2. 识人用人是"评估与配置"工具，**只用于组队、分工、合作，绝不用于构陷、排挤、整人、拿捏他人**。
3. 众谋独断 ≠ 闭门拒谏：收集期必须真听异见，拍板后的反复摇摆才是弊病；用"独断"为"从不听劝"洗白，是滥用。
4. 不得以"反经"为名去打破规则做违法、缺德、损害他人之事——权变只在策略层面换道，不越底线。
5. 换道成本要算清：若旧打法只是偶发失误就仓促换道，会变成"狗熊掰棒子"；先过第一步"验常经"再谈变。

## 六、案例示例

**案例一（RoboCon 带队 · 权变与用人）**：队伍连续两届在赛场上栽在同一个环节——机械臂手动对位调试，赛前练得很顺，赛场一慌就崩。今年赛题加了视觉自动定位要求。
- 背景：老打法（人眼对位）在"赛场高压 + 新规则"两个变量同时变化后彻底失效，再加班练手速也补不回来。
- 走逻辑链：验常经——近三次关键调试成功率逐场下降，常经已失效；辨时势——变量是"赛场压力"与"视觉定位新规"，非执行问题；广咨众谋——列三条路：A 苦练手速、B 上视觉自动对位、C 降低对位精度走容错设计，专问保守派"B 风险是不是太大"；量人——机械型队员擅长结构、代码型队员擅长视觉，B 路线正好把视觉环节交给对口的人，其"手速短项"被自动方案补掉；独断——按胜算×代价拍板 B 为主、C 为兜底，拍板后全队停止争论；设哨——赛前三天内连续 20 次对位成功率达 95% 才算 B 成立，否则切 C。
- 结论：换道不是否定过去，是承认变量已变；用人不是求全能，是把长项放到新打法的关键位上。

**案例二（MOBA 对局 · 众谋独断）**：队伍经济落后，队友两派吵翻——一派催"快接团拖不住"，一派喊"别团继续带线发育"，公屏刷屏，节奏越打越乱。
- 背景：按"大家说的办"等于谁声大听谁的，节奏必崩。
- 走逻辑链：验常经——此前两次接团皆以暴毙告终，"接团"这一常经在经济落后时已失效；辨时势——失效根源是经济差，非配合问题；量人——催团者是经济领先的核心位（他的"长项"是收割，接团对他有利），落后位接团等于送经济；独断——作为节奏主导者闭门定：经济差 3k 之前不主动接团，只带线补经济，团只在己方追平后接；设哨——经济追平信号出现才转打团。
- 结论：众谋听的是信息，独断守的是节奏——把两派意见当信息收，不当决策投票。

## 七、与帝御体系联动

- **归层**：权衡之经。以**主见层·独见守己**为主导——「辨」（辨清常规为何失效、辨清每派建议各自站在谁的利益与长项上）＋「见」（清醒判断该换哪条路、该把谁放到哪个位）；辅以**御势层·权变**（兵无常势，与时迁移，与《孙子》「兵无常势，水无常形」、《三十六计》借势破局互为表里）。
- **诀系**：独见守己之辨 + 见 + 御势（权变）+ 格（观界：知己知彼，量人配路）。
- **调度方式**：帝御定位处境为"常规打法失灵 / 需识人分工 / 意见冲突需独断"时，经万法归宗·权衡之经索引触发本子技能，独立加载并按「推演逻辑链」执行；与主文件分工——主文件给「独见守己」辨/见/守/己的定性纲领与御势层六步，本文件给《反经》"验常经→辨时势→众谋→量人→独断→设哨"的完整换道操作法；与《韩非子》分工——韩非辨"谁在获益"，反经断"该换哪条路、人怎么摆"。
