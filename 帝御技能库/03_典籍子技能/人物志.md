# 《人物志》· 帝御子技能

## 一、典籍定位

《人物志》（魏·刘劭）是帝御权衡之经里的"系统识人学"：它不凭相面、不凭直觉，而是给一套**由外见内、由静见变、由处境见本性**的观察方法——先从神、精、气、色、仪、容、言九处初判，再放到得失利害的动态情境里验真，最后反照自己。适用于招人、选队友、合伙、辨伪与自我认知校准，是把"识人"从玄学变成可操作测评的手册。

## 二、核心公理

- **九征观质，由外见内**：「平陂之质在于神，明暗之实在于精，勇怯之势在于筋，强弱之植在于骨，躁静之决在于气，惨怿之情在于色，衰正之形在于仪，态度之动在于容，缓急之貌在于言。」（《人物志·九征》）帝御化：一个人的质地会从九个出口漏出来——**神**（眼神气度正不正、邪不邪）、**精**（谈吐思路明不明、糊不糊）、**气**（情绪稳不稳、急不急）、**色**（脸色藏不藏事、喜怒形于色否）、**仪/容/言**（举止、姿态、语速）。落动作：初判一个人，先扫这九处做"客观记录"，别只听他自我介绍；九处里两处以上明显打架（如嘴上说大度、神色却护食），就先挂个问号。
- **八观察行，于变审常**：「八观：一曰观其夺救以明间杂，二曰观其感变以审常度……七曰观其所短以知所长，八曰观其聪明以知所达。」（《人物志·八观》）帝御化：人在平静无利害时都装得体面，**真本性藏在"感变"——得失、利害、变故瞬间的反应**里，那才是他的"常度"。尤其两条最实用：观其夺救（看他对强弱、上下是否两副面孔）；观其所短以知所长（偏狭之人往往其正处极正，他的短反过来就是他的长——较真者可守规、木讷者可托事）。
- **五视察变，处境见性**：同旨可参李克观人法——「居视其所亲，富视其所与，达视其所举，穷视其所不为，贫视其所不取。」（《史记·魏世家》）帝御化：人在不同处境下藏不住——**闲时跟谁混（所亲）、有钱怎么花（所与）、有权举谁（所举）、落魄时不肯做什么（穷所不为）、没钱时不取什么（贫所不取）**。五个处境凑齐四个以上，本性基本定型。落动作：评估一个人时，不要只问他"现在怎样"，要问他"最难/最富/最有权时分别怎样"。
- **自知为明，先察己再察人**：「夫圣贤之所美，莫美乎聪明；聪明之所贵，莫贵乎知人。」（《人物志》自序）；又「知人者智，自知者明。」（《老子》第三十三章）帝御化：读人之前先把自己的长/短与偏见列清——**自己缺什么，最容易误读成"别人也这样"或"别人就该补我这块"**。落动作：每次重要识人前先写三行：我自己的短板是什么、我此刻偏好什么类型的人、这会不会让我偏判。

## 三、适用场景清单

1. 招人/选队友/找合伙：要判断这人能不能一起扛事、放哪个位。
2. 判断新人靠不靠谱：刚认识的合作方、朋友、对象，热情得体面但需要验真。
3. 识人辨伪：嘴甜面善型、PPT型选手，需要拆穿"平静面具"。
4. 自我认知校准：觉得自己看谁都不准，需要先校正自己这把"尺"。
5. 组队分工：一队人谁担技术、谁担沟通、谁担兜底，按长项配岗。
6. 面试/被面试：需要读懂候选人真实质地，或反向读懂面试官真正考察什么。

## 四、推演逻辑链

1. **先自知**：写清自己三项长、三项短，以及当下对"理想队友/理想合作者"的偏好——作为读人的校正尺，防止把自己的欲望投射到对方身上。
2. **九征初扫**：第一印象阶段，从神、精、气、色、仪、容、言九处做**客观记录**（只记看到什么，不急着下好坏结论）；记录中两处以上打架，标"存疑"。
3. **感变验真**：等或观察一个小利害情境（分钱、背锅、加班、被夸、被当众纠正、赶限时任务），看其在压力下的反应是否与"平静时"一致——一致则可信一层，两张脸则下调。
4. **处境五视**：按五视追问/侧面了解——他闲时亲近谁、难处拒绝过什么、利益当前先取什么、落魄时守住了哪条线。凑齐四处即基本定性。
5. **夺救间杂**：专查"两副面孔"——对上（强者/领导）与对下（弱者/新人）是否两套态度；对弱者如何，比对强者如何更能照出本性。
6. **短中见长**：不只挑毛病，从其短反推其长——较真者配守规岗、木讷者配托事岗、张扬者配对外岗；把短项用机制补，不要求人改成长项。
7. **定级配岗**：综合给此人定"质地"并配"位置"，同时写下存疑处与观察期——一次观察不定终身，留三个月复验窗口。

## 五、约束边界

1. 九征是**行为倾向的观察假设，不是相面算命**：不搞骨相、气色迷信，它只是初筛入口，必须经第三、四步情境验证才算数。
2. 识人用于合作、分工、择友，**绝不用于标签歧视、职场排挤、构陷整人、以貌取人否定一个人的全部价值**。
3. 观察要在**自然情境**里进行，不得故意设圈套、制造危机去试探他人人品——那是钓鱼，不是识人。
4. 人会成长：一次观察只定"当前"，存疑处留观察期复验，不盖棺定论。
5. **对亲密关系不靠"测评"**：家人、伴侣、挚友以真诚与袒露为先，把九征八观带回家反复测评，会杀死信任。

## 六、案例示例

**案例一（选队友 · 八观五视）**：组队参加比赛/项目，两个候选人都很积极，一个面试时谈吐漂亮、一个话少但手快。
- 背景：按"第一印象"必选谈吐漂亮者，但那只是九征中的"精、言"两项。
- 走逻辑链：先自知——我自己偏好会表达的人（需校正）；九征初扫——A 神采飞扬、言辞流畅，B 气定神闲、话少但动手快，两人九征记录并列；感变验真——给一个限时小任务并人为制造"方案被否"的压力：A 急着辩解、B 沉默两分钟后直接改出新版；处境五视——问两人此前项目在"缺人缺钱"时的做法：A 说"那时候主要靠大家热情"，B 说"我那时候把非核心功能砍了保主线"；夺救间杂——观察两人对实习生：A 使唤、B 带教；定级配岗——A 配对外汇报/对接岗（其"爱说"之长），B 配核心执行岗。
- 结论：谈吐漂亮是"精、言"两项的分，扛事要看"感变"与"五视"；选队友不是选面试表现最好的，是选压力下反应最稳的。

**案例二（识人辨伪 · 夺救间杂）**：社交圈里一个人酒桌上极热情、夸夸其谈，称兄道弟，但几次合作分钱时都把功劳往自己身上揽。
- 走逻辑链：九征初扫——他仪、容、言皆佳（面子分高）；感变验真——分钱/争功关头，其"色、气"暴露真实偏好；夺救间杂——对上（有用之人）热情、对下（无用人）冷落，两副面孔明显；处境五视——"贫视其所不取"：他在无利可图时是否还愿意付出？观察为否。结论：此人对上谄媚、对下争利，不可托付核心利益，只可做浅层往来。
- 结论：平静时人人都体面，"夺救"关头才照得出里子。

## 七、与帝御体系联动

- **归层**：权衡之经。以「见（清醒判断）」为主导——先察己再察人，知人自知方为明断；辅以心法层「恭（扶宏察微）」——宏观上把人放到团队格局里看该配哪个位，微观上盯九征每一处神色语气的细节。
- **诀系**：见（洞察·察人自知）+ 恭（察微）+ 格（观界：把人摆进格局定其位）。
- **调度方式**：帝御定位处境为"识人 / 选队友 / 辨伪 / 自我认知校准"时，经万法归宗·权衡之经索引触发本子技能，独立加载并按「推演逻辑链」执行；与主文件分工——主文件给「见」与「恭」的定性纲领，本文件给《人物志》九征—八观—五视的完整测评流程；与《鬼谷子》分工——鬼谷在谈判中读对方"当下要什么"，人物志系统测一个人"底色是什么"，一纵一横，合观方全。
