# 《帝范》· 帝御子技能

## 一、典籍定位

《帝范》是唐太宗写给太子的帝王教科书，共十二篇（君体、建亲、求贤、审官、纳谏、去谗、诫盈、崇俭、赏罚、务农、阅武、崇文），是帝御御势层的"为君统御学"：它不讲一场仗怎么打（那是《孙子》《三十六计》），也不讲怎么收拢人心（那是《三略》），而讲**一个居于上位、要带队伍立规矩的人，自身该修什么心、用什么人、防什么病、守什么本**。它与《三略》互补——三略讲"德威比例"的收心术，帝范讲"君者自身的体、用、戒"：君体要宽平，用人要量才，听言要纳谏去谗，得志要诫盈崇俭，治事要赏罚务农。适用于带队、负责、立规则、防内耗、防骄，是把"恭（扶宏察微）"落到"上位者先正己再正人"的工具书。

## 二、核心公理

- **君体宽平（志宽心平）**：「宽大其志，足以兼包；平正其心，足以制断。」（君体）帝御化：居上位者两件命门——**志要宽**（格局大到装得下不同意见、不同性格的人、不同阶段的失败），**心要平**（心不偏不躁，才裁得准、断得公）。落判断：此刻你是被"这点事都容不下"卡了（志不宽），还是被情绪带着偏私了（心不平）？容不下异见、听不得批评、一断就带情绪，君体先亏，后面所有赏罚用人都是歪的。
- **量才审官（用人如用木）**：「明主之任人，如巧匠之制木……智者取其谋，愚者取其力，勇者取其威，怯者取其慎，无智勇怯，兼而用之。」（审官）帝御化：没有废人，只有放错位置的料——智者放谋断位、力者放执行位、勇者放攻坚位、谨慎者放把关位。落动作：盘点手里的人时，不问"这人好不好"，问"这块料该做成什么家具"；把人当材料用，不当情绪靶子用。
- **求贤在诚，用人不疑**：转述求贤、审官两篇大旨——明君求贤若渴，既得其人则任之不贰。帝御化：求贤靠的是真需求真尊重（不是作秀），用人靠的是敢授权敢担底。落判断：你是不是嘴上求贤、真给权又处处掣肘？疑而用之，人必离心；既用之则在其位授其权、替他担责，打了板子先查自己派位与授权有没有问题。
- **纳谏去谗（广言路、远小人）**：「夫谗佞之徒，国之蟊贼也。」（去谗）帝御化：队伍最大的内伤不是对手强，是**谗言与蔽塞**——报喜不报忧、传话传话、借你之手整人。落动作：主动开辟"能听到坏消息"的通道（定期一对一、匿名渠道、让反对者说话），同时对"专在你耳边说人坏话、却拿不出事实验据"的人立刻降权。纳谏不是什么都听，去谗不是搞肃反，而是**让真实信息流得进来、让挑话的人没有市场**。
- **诫盈崇俭（满招损、节用固基）**：转述诫盈、崇俭两篇大旨——业隆则戒盈，居高则崇俭，节用而务本。帝御化：人在顺境、被吹捧、手里有权时，最容易骄奢膨胀——规矩为自己开口子、用度上讲排场、听不进逆耳话。落自检：最近是不是有人顺着你说、你开始觉得"我果然厉害"？这一刻就是诫盈的触发点；崇俭落到现代不是抠门，是**不把资源花在撑场面、立人设上，而花在固本（能力、团队、基本盘）上**。
- **赏罚明信，务农固本**：转述赏罚、务农两篇大旨——赏罚所以明劝惩，务农所以固邦本。帝御化：赏罚是上位者的公信力，说了就兑现、违了就追责，一次破例威就漏一次；务农是"务本"——任何队伍都有养活自己的根本（产品、主业、现金流、核心技能），根本不牢，一切排场都是空转。落判断：你的"本"是什么？这周是在固本，还是在为枝叶热闹奔忙？

## 三、适用场景清单

1. 自己当负责人/组长/团长：要立规矩、立权威，先修"君体"再开口派活。
2. 用人分派：手里几个人不知道谁该放哪，需要"量才如用木"地对位。
3. 防谗言内耗：队伍里有人传话、打小报告、报喜不报忧，信息开始蔽塞。
4. 被吹捧易骄：连赢连胜、众星捧月，需要诫盈降温，防止规矩为自己开口子。
5. 赏罚两难：该赏怕惯坏、该罚怕伤人，需要按明信原则立一次规矩。
6. 务本焦虑：忙了一圈发现热闹都在枝叶上，根本（主业/产品/现金流）在荒芜。
7. 授权困境：想用人又处处不放心，需要分清"求贤在诚"与"用人不疑"的边界。

## 四、推演逻辑链

1. **正君体（恭·扶宏）**：先检自己——志宽不宽（容不容得下异见与失败）、心平不平（断事带不带情绪）。君体不正，后面四步全歪；先把这一关过了再谈带队。
2. **盘料对位（审官）**：逐人盘点"这块料是什么木"——善谋、善力、善勇、善慎，各归其位；对放错位的人做一次岗位再分配，把重要任务押在试过、放对位的人身上。
3. **通言路（纳谏）**：建一条"坏消息能到你耳朵"的通道——固定一对一、留反对意见的席位、主动问"现在最糟的是什么"；同时识别并降权"只传闲话、不办实事"的谗佞者。
4. **立明信（赏罚）**：把该兑现的赏兑现、该追责的追责，规矩面前对自己一样严；立威一事一议，只对破坏全局的行为，不搞情绪发泄。
5. **诫盈崇俭**：顺境触发自检——是否开始为自己开口子、为排场花钱、听不进逆耳？把资源从"撑场面"切回"固本"。
6. **务农固本**：重新确认本业（产品/主业/现金流/核心技能），把本周优先级的大头压在本业上，砍掉枝叶上的无效热闹。
7. **验回流**：一轮之后看指标——坏消息流得进来了吗（言路）、人放对位后出活了吗（审官）、赏罚兑现后人心服吗（明信）、根本回稳了吗（务农）；任一指标不转，回到对应那一步重修。

## 五、约束边界

1. **只做局势与组织管理分析，绝不用于现实权谋、整人、驭下算计、人身控制**——帝范讲的是上位者的修身与带队本分，不是教人防人、整人、玩弄权术。
2. 量才审官是"把人放对位置"，不是把人当工具消耗；用人不疑的前提是已"八征"式试过、信息透明，而非闭眼盲信。
3. 纳谏去谗是为了信息真实，不是鼓励互相打小报告、搞内斗；对谗佞者降权对事不对人，不搞清洗式肃反。
4. 诫盈崇俭是上位者的自律条款——约束的首先是调用者自己（规矩不为自己开口子），不是用来苛责下属、克扣团队合理福利。
5. 赏罚明信的底线：赏不避仇、罚不避亲，但罚不能罚到伤人，赏不能赏成供养；公信力一旦透支，须先修信再谈管理。

## 六、案例示例

**案例一（RoboCon带队·君体+量才）**：你是机械组组长，赛前进度落后，组员A三次提交不达标，你心里冒火想当众骂一顿换掉他。
- 背景：情绪上头，君体（心平）已亏；直接处罚是把"管理"做成了"发泄"。
- 走逻辑链：正君体——先压下火，志要宽（A的失败是全队进度问题的一部分，不是他一个人的罪）；盘料对位——A擅长三维建模、不擅长现场调试，是放错了位置；通言路——一对一问清他是不是怕被踢才硬扛；立明信——定一条"节点延交必须说明原因"的公开规矩，对事不对人；务农固本——把本周大头压在整机结构冻结这条本线上。
- 结论：A从现场调试调到图纸迭代岗，输出反而提速；规矩公开立下，没人再觉得组长凭情绪办事。

**案例二（率土带队·诫盈+去谗）**：你是分团指挥，连下两城后团里一片吹捧，有人开始在你耳边说另一分团长的坏话，想借你之手压制对方抢功。
- 背景：顺境触发诫盈，谗言开始流入。
- 走逻辑链：正君体——志宽心平，不因连赢飘起来；去谗——对"只说人坏话、拿不出协同事实验据"的传话者当场降权，不接这个话头；通言路——直接找对方分团长核对战局，不听二手传话；立明信——战后战功按公开战绩排行兑现，不按耳边话分功；务农固本——把资源压在守住已下城池、发展垦田（本业）上，不压在争指挥权的热闹上。
- 结论：谗言没有市场，两个分团仍协同；连赢后没有因内耗崩盘。

## 七、与帝御体系联动

- **归层**：御势层（统御）——与《三略》（德威收心）、《六韬》（全局将略）互为表里：六韬讲怎么摆开一盘棋，三略讲怎么把人心收拢，帝范讲**下棋的那个人自己要修成什么样**（君体、量才、纳谏、诫盈、务农）。
- **诀系**：恭（扶宏察微——扶全局之本、察一人之言路与状态）为主；辅以俭（崇俭务本、积微固本）与让（志宽兼包、容异见容人）。
- **调度方式**：帝御定位处境为"带队负责/立规则权威/防谗言内耗/被吹捧防骄"时，由御势层索引触发本子技能，按「推演逻辑链」输出"正君体→盘料对位→通言路→立明信→诫盈→务农→验回流"的为君统御方案；与主文件分工——主文件给"御势层（统御）＋恭"的映射口径，本文件给《帝范》十二篇的上位者修身与带队操作法。
