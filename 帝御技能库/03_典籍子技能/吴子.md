# 《吴子》· 帝御子技能

## 一、典籍定位

《吴子》是帝御体系中"固本与出击次序"的标尺：吴起用兵最反的就是两种死法——一种是只顾修身养性、武备废弛被人灭掉（承桑氏），一种是仗着人多好勇逞强把自己耗死（有扈氏）。它给出的活法是"内修文德、外治武备"两手都硬，且**先把自己整明白（治），再去看敌人虚实（料敌），最后才谈打**。适用于"先打基础再行动""根基未牢时被怂恿扩张""出手前判断敌情与自身状态"，是把凝本存资层的"固本"和御势层的"应变"接成一条次序链的工具书。

## 二、核心公理

- **内修文德，外治武备**：「昔承桑氏之君，修德废武，以灭其国；有扈氏之君，恃众好勇，以丧其社稷。明主鉴兹，必内修文德，外治武备。」（图国）帝御化：两条腿缺一不可——只练内功不练硬实力（技能、作品、基本盘），等于修德废武，一遇竞争就被碾；只猛冲不补内功，等于恃众好勇，赢了也守不住。落自检：你现在是偏"文德"（想法多、积累薄）还是偏"武备"（冲得猛、根基虚）？往弱的那条腿补。
- **以治为胜**：「兵何以为胜？……以治为胜。……若法令不明，赏罚不信，金之不止，鼓之不进，虽有百万，何益于用？」（治兵）帝御化：赢不赢，首先不看人数多不多、资源多不多，看的是**组织度/自身秩序**——你自己的基本功、流程、习惯是不是稳固可重复。一千个散乱的人不如一百个有秩序的人；一个方向散乱的人不如一个把基本动作做扎实的人。落判断：你要扩出去的事，基本动作已经稳定可重复了吗？没有，先"治"，不谈规模。
- **料敌虚实而后趋危**：「用兵必须审敌虚实而趋其危。」（料敌）帝御化：打之前先看清楚——对方/这件事的薄弱处到底在哪，别凭一腔热血就冲。虚在哪（资源薄弱？注意力分散？内部不和？）就往哪打；实的地方坚决不碰。落动作：出手前花同样多的时间做"敌情判断"，而不是只花时间准备"怎么打"。
- **战胜易，守胜难**：「战胜易，守胜难。……天下战国，五胜者祸，四胜者弊，三胜者霸，二胜者王，一胜者帝。是以数胜得天下者稀，以亡者众。」（图国）帝御化：赢一场不难，难的是连续赢还不把自己耗死。频繁对外动武（频繁扩张、频繁换赛道、频繁硬刚）的，看似常胜，实则把本耗光了。落判断：你最近是不是一直在"赢"——项目一个接一个、局一局接一局？赢的次数多了，先停一下补"守胜"（巩固成果、回血），再谈下一战。
- **先戒为宝**：「夫安国家之道，先戒为宝。」（料敌）帝御化：平安稳当的时候就把警戒和预案备好，别等火烧眉毛。落动作：在一切顺利的阶段，先问"如果明天出意外，我的第一反应是什么"——预案现在写，出事时不慌。

## 三、适用场景清单

1. 先打基础再行动：想做一件事（学技能、做产品、冲比赛），但基本功还不牢。
2. 根基未牢时被怂恿扩张：有人劝你"趁热打铁""再开一条线""赶紧All in"，需要判断能不能扩。
3. 判断"现在能不能出手"：一个机会摆在面前，不知是时机到了还是该再等等。
4. 出手前的敌情判断：竞争/博弈已经确定要打，需要先看清楚对手虚实再定打法。
5. 连续赢后的冷却：最近项目/对局顺风顺水，需要警惕"数胜必耗"、主动回血巩固。
6. 自身状态自检：身心、能力、资源是否已经稳到可以对外输出。
7. 反例自查：是在"修德废武"（光想不练）还是"恃众好勇"（光冲不补）。

## 四、推演逻辑链

1. **固本自检（先治己）**：先不动别人，先盘自己——把"内修文德"（认知、习惯、身心状态）和"外治武备"（硬技能、作品、基本盘资源）两条腿分别打分。哪条腿低于及格线，先补哪条。
2. **过"以治为胜"关**：问一个硬问题——你要扩出去的那件事，基本动作是不是已经能稳定重复地做出来（不是偶尔做成一次）？答不上来，回到"治"，不进入下一步。
3. **料敌虚实**：自身站稳后，花同等精力看外部——对手/机会的"实"在哪、"虚"在哪（薄弱环节）、它的状态是骄、是疲、还是乱。把"虚"的那个点标出来。
4. **定打法**：只往"虚"处打，不碰"实"处；打法和敌情匹配——敌疲则扰、敌乱则乘、敌实则避。敌情判断错了，打法再漂亮也是白送。
5. **算"守胜"账**：出手前先算这一仗打完怎么巩固——赢下来的东西拿什么守住、消耗掉的精力拿什么补。算不过账的仗，再诱人也不打。
6. **先戒收尾**：行动同时备好预案——如果第一波没打中、如果对方反扑、如果自己状态下滑，退路和第二方案是什么。预案写下来，再动手。
7. **战后固本**：每打完一轮，不论胜负，先回到第1步补自身——胜了补"守胜"，败了补"治"，带着补好的根再谈下一战。

## 五、约束边界

1. **只做局势与博弈分析，绝不用于现实暴力、冲突、人身对抗、阴谋算计**——"料敌、趋危"是竞争分析与项目打法，不是教人主动攻击谁、整谁。
2. "固本"不是拖延的借口：自检发现根基薄，动作是"补基础"，不是"再等等看"；以"还没准备好"为名长期不动手，和"恃众好勇"一样是病。
3. "先戒为宝"是备预案，不是焦虑放大：预案准备到"有退路"即可，不必为小概率意外消耗全部心神。
4. "战胜易守胜难"约束调用者：连续胜利时强制冷却复盘，不许被连胜推着一路扩张；低谷时也不许自我否定到不敢出手。
5. 敌情判断（料敌）用于正当竞争与自我决策，不用于打探、抹黑、恶意针对具体的人或公司。

## 六、案例示例

**案例一（被怂恿扩张·固本检验）**：你大二，机器人工程课设刚做出一个小demo，有人劝你"赶紧再开三个方向、做个完整产品拿去比赛、顺便接外包"。
- 背景：声音很热闹，但你自己知道demo只跑通过一次。
- 走逻辑链：固本自检——内修（课程基础）尚可，外治武备（工程熟练度、可重复交付能力）不及格；过"以治为胜"关——demo只跑通过一次，基本动作不稳定，判定"不能扩"；料敌——看清那个劝你的人是热闹说话还是真懂交付，其判断不做依据；定打法——不接外包、不开三线，把同一个demo在不同条件下稳定复现五次，把它从"碰出来的"练成"造得出来的"；先戒——三个月后再评估是否比赛。
- 结论：三个月后demo稳定度够了，才第一次参赛；没在根基虚时被一波热闹带崩。

**案例二（对局博弈·料敌虚实）**：MOBA排位，对面下路组合前期强势，你方打野想抓下建立优势。
- 背景：对面下路确实强，但打野想硬抓。
- 走逻辑链：固本自检——我方下路状态不佳、打野节奏一般，自身并不占优；过"以治为胜"关——我方基本运营（补刀、视野）没站稳，不宜主动找架；料敌虚实——观察对面：下路"实"（对线强），但打野"虚"（已连续刷野失误两次、视野空白）；定打法——不碰下路实处，打野避开下路，转而抓对面视野空白的上半区；算守胜账——抓成后立刻拿龙推塔巩固，不浪；先戒——若对面下路转上支援，提前留撤退眼。
- 结论：不撞实处、专打虚处，节奏反过来握在手里。

## 七、与帝御体系联动

- **归层**：凝本存资层（固本）为主——先把自己这条腿补硬；御势层（应变）为辅——根站稳后，再用"料敌虚实"决定怎么对外打。
- **诀系**：恒（保无竭、给时间伟量——固本要时间）＋ 凝（积微成势——把基本动作练到稳定重复）＋ 御势（料敌应变）。
- **调度方式**：帝御定位处境为"先打基础再行动/被怂恿扩张/判断能否出手/连续胜利后需冷却"时，由凝本存资层与御势层联合索引触发本子技能，按「推演逻辑链」走"固本→过治关→料敌→定打法→算守胜→先戒→战后固本"的完整次序；与主文件分工——主文件给"凝本存资（固本）＋御势"的映射口径，本文件给《吴子》的固本检验标准与料敌应变操作法。
