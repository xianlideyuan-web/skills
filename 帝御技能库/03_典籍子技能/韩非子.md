# 《韩非子》· 帝御子技能

## 一、典籍定位

《韩非子》是帝御权衡之经里的"利益透视镜"：它不教你算计人，而教你把一切话术、规则、引导先翻译成"利益结构"——谁因此获益、谁为此付出、这套规则为谁服务。适用于识别裹挟、看清组织与舆论背后的博弈利益、判断一条引导该不该跟随，是「独见守己（辨）」最硬的底子：先辨利益，再决定听不听。

## 二、核心公理

- **利在其中，言方动人**：「舆人成舆，则欲人之富贵；匠人成棺，则欲人之夭死也。非舆人仁而匠人贼也，人不贵则舆不售，人不死则棺不买。情非憎人也，利在人之死也。」（备内）帝御化：人说什么、劝什么、推什么，背后先看他的"卖品"是什么——他造轿子就盼你富贵，他造棺材就盼你有人死。不是他人好或坏，是他的利益结构决定了他的嘴。落动作：任何"为你好"的建议出口，先问一句——他靠这件事赚什么？
- **趋利为本，亲疏皆然**：「医善吮人之伤，含人之血，非骨肉之亲也，利所加也。」（备内）帝御化：连医者的悉心，都不是出于亲疏，而是利益所在。推到人际：热情、冷淡、劝说、阻拦，背后多半挂着一根"利"的线——可能是钱、是面子、是权力、是安全感。不据此怀疑一切善意，但据此多问一层"这根线拴在哪"。
- **法要成文，术藏胸中**：「法者，编著之图籍，设之于官府，而布之于百姓者也；术者，藏之于胸中，以偶众端而潜御群臣者也。」（难三）帝御化：我们只取其"规则观"：真正可执行、可预期的规则必须是公开、成文、摆在明处的；凡是只在少数人心里、随口变化、"你自己体会"的规则，都是偏向性规则——它随时可以向制定者倾斜。落判断：你所处的环境里，规则是写下来人人可见，还是在某人的肚子里？后者的利益天然偏向他。
- **世异事异，规则随利变**：「世异则事异，事异则备变。」（五蠹）帝御化：没有永恒合理的规则，只有"当下利益结构下"合理的规则。时代变了、当事人变了、利益盘子变了，旧规则就可能变成保护既得者的壳。落动作：面对一条权威规则，不只问"对不对"，更问"它是在什么利益格局下立的？现在那个格局还在吗？谁还在靠它获益？"

## 三、适用场景清单

1. 被"为你好"包围：家人、领导、KOL、销售热情推荐一条路，情绪上动摇，需要先辨其利益立场。
2. 看清博弈利益：项目、对局、商业谈判、舆论争论中，各方说辞混杂，需要画出"谁在获益"的结构图。
3. 识别裹挟：感觉被潮流、群体情绪、道德话术推着走，说不清哪里不对，需要拆穿"这剧本成全的是谁"。
4. 判断规则偏向：公司制度、平台规则、群规、合同条款不公平时，分析它实际保护谁、约束谁。
5. 面对表面话术：宣传语、招聘话术、促销噱头、感情话术包装精美，需要剥到利益内核。
6. 自身决策被"大义"绑架时：先算清这笔账最终由谁埋单，再决定投入与否。

## 四、推演逻辑链

1. **抓话术**：把当前最响的那条引导（劝你做/不做某事的声音）原样记下——是谁说的、用什么理由、催不催你立刻行动。
2. **列利益方**：围绕这件事列出所有相关角色（说话者、你、平台、大众、沉默的第三方），逐一方问：这件事成了，他得到什么、失去什么？
3. **定获益重心**：判断利益流向的重心在哪一方——若最大收益归说话者、最大成本归你，则这条话术本质是"成他"，不是"成你"。
4. **审规则成色**：此事涉及的规则是公开成文、可预期、对双方一致，还是黑箱、随人解释？后者本身就是偏向性证据。
5. **查话术与利益是否一致**：说话者嘴上说的理由（为你好/正义/大局），与他实际获益方向是否吻合？吻合则可信一层；明显错位，则话术只是包装。
6. **落己断**：把以上结论译成自己的判断——这条路对我（长期、真实）是成己还是成他？是成己则跟，是成他则客气拒绝或另择；不被"大义"裹挟，也不因多疑而拒绝所有善意。

## 五、约束边界

1. **只做客观局势与利益分析，绝不用于驭下权谋、操控他人、职场倾轧、构陷排挤**——本skill是"看清"的工具，不是"整人"的手册；《韩非子》原典中"驭臣、防臣、伺察"等术法一律不取、不演、不教。
2. 利益分析不等于"以恶意度人"：先假设善意成立，再用利益结构验证；验证不成立才下调信任。习惯性把所有人往坏处想，会把自己活成孤家寡人。
3. 不用于撕裂亲密关系：对伴侣、家人、挚友的关心，不得套用"谁在获益"去逐句审问——那不是清醒，是冷漠；利益透视只用于有博弈、有资源交换、有规则约束的场合。
4. 看清之后不必点破：本skill输出的是自己的判断与立场，不承担去揭穿、对线、教育对方的义务；看破不说破，是保护自己的姿态。
5. 与帝御「独见守己」配合：辨清利益之后，选择权仍在己——可以选择合作共赢，也可以选择不陪玩，但决定必须基于事实利益，而非情绪赌气。

## 六、案例示例

**案例一（被裹挟·规则为谁服务）**：入职一家初创公司，HR热情介绍"弹性工作、扁平管理、大家庭文化"，同时暗示要签长期自愿加班协议。
- 背景：话术全是褒义词，但隐约觉得哪里不对。
- 走逻辑链：抓话术——"大家庭、弹性、扁平"；列利益方——公司（获得低固定成本的超长工时）、员工（获得什么？）、HR（招人指标与奖金）；定获益重心——最大收益明显归公司与HR，"弹性"实际指向的是"随时可要求你在线"；审规则成色——加班协议是"自愿"但与转正、晋升挂钩的隐性黑箱规则；查话术一致性——嘴上"弹性"，实际"随叫随到"，错位明显；落己断——这不是福利包装成的剥削，而是"用温情话术降低你的议价警觉"。行动：签字前把"弹性"的边界用书面问清，问不清就降薪预期或不签。
- 结论："大家庭"三个字的成本，最后是员工用加班还的。

**案例二（对局博弈·谁在获益）**：MOBA对局中，队友不断发信号催你"快团、别带线、别发育"，而他自己是经济领先的核心位。
- 背景：听起来像团队协作，但节奏一直崩。
- 走逻辑链：抓话术——"快来团！"；列利益方——队友核心位（团赢他收割人头扩大优势）、你（你是落后位，接团暴毙送经济）；定获益重心——催团的最大受益人是他，最大风险承担者是你；落己断——他需要的是"你的命换他的节奏"，不是团队共赢。行动：不为队友情绪所裹挟，继续带线补经济，团只在己方经济追平后接。
- 结论：催你的话术和他的站位，往往不在同一个利益点上。

## 七、与帝御体系联动

- **归层**：主见层（中立己）为主，主导诀「独见守己（辨）」——辨引识向，先辨清每道声音背后的立场与获益者；辅以凝本存资层「格（观界）」——把各方利益与资源摆成格局，观界而定吉凶。
- **诀系**：独见守己之辨 + 格（观界）+ 见（清醒判断）。
- **调度方式**：帝御定位处境为"被外界引导/裹挟、需看穿话术与规则偏向、判断博弈利益结构"时，经万法归宗·权衡之经索引触发本子技能，独立加载并按「推演逻辑链」执行；与主文件分工——主文件给「独见守己」辨/见/守/己的定性纲领，本文件给《韩非子》"谁在获益"的完整利益透视操作法。
