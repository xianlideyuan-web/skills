# 《素书》· 帝御子技能

## 一、典籍定位

《素书》（旧题黄石公授张良，凡一千三百余言）是帝御内炼之经里的**"修身—统同源手册"**。它不教权术，教的是"什么样的人立得住、带得动人"。原文框架须完整保留为六章骨架：

- **原始章第一（道）**：立总纲——「夫道、德、仁、义、礼，五者一体也。」并逐一定义。
- **正道章第二（德）**：立人之品级——「德足以怀远，信足以一异，义足以得众，才足以鉴古，明足以照下，此人之俊也。」
- **求人之志章第三（仁 / 修身治学）**：列一串"所以……"的修身接人条目（绝嗜禁欲、博学切问、近恕笃行、亲仁友直等）。
- **本德宗道章第四（义 / 修心定术）**：列"长莫长于……安莫安于……吉莫吉于……"的志心笃行之术（吉莫吉于知足、苦莫苦于多愿等）。
- **遵义章第五（礼 / 赏罚决断）**：讲赏罚、用人、戒惧之道（小功不赏则大功不立、小怨不赦则大怨必生、畏危者安畏亡者存等）。
- **安礼章第六（礼之运用 / 盛衰之几）**：讲积善积恶、得人失士、见已失慎将失的盛衰几微。

总纲一句贯穿全书：**道、德、仁、义、礼不是五样分开的修养，而是一个整体的五面，修身与带队伍用的是同一套底子。**适用于修身立心、带小团队立德收心、赏罚失衡、判断一个人德性根基——是把"内修"直接接到"外统"的那座桥。

## 二、核心公理

- **五者一体，缺一则裂**：「夫道、德、仁、义、礼，五者一体也。」（原始章）帝御化：五者本是一体，**缺一面整面塌**。落判断：你带团队若只讲礼（规矩考核）不讲仁（关心人），人会散；只讲仁（一团和气）不讲义（赏罚分明），事会烂；只埋头干不照下（缺明），下面不服。自查此刻团队 / 自己身上，裂的是哪一面。
- **五德各有定分（道履得宜亲）**：「道者，人之所蹈，使万物不知其所由；德者，人之所得，使万物各得其所欲；仁者，人之所亲，有慈惠恻隐之心；义者，人之所宜，赏善罚恶，以立功立事；礼者，人之所履，夙兴夜寐，以成人伦之序。」（原始章）帝御化：五德不是空话，各有可操作的所指——**道**（你日常所走的路 / 方向，脚下踏的对不对）、**德**（行道而有得于身，让人各得其欲）、**仁**（慈惠恻隐、让人愿意亲近你）、**义**（赏善罚恶的恰宜，事能立得住）、**礼**（人伦次序、早晚践行的规矩）。落自评：方向对不对（道）？自己有没有真得（德）？人愿不愿亲（仁）？赏罚公不公（义）？次序明不明（礼）？
- **俊者五资，德先于权**：「德足以怀远，信足以一异，义足以得众，才足以鉴古，明足以照下。此人之俊也。」（正道章）帝御化：让人愿意跟着你，靠的不是头衔权力，是五样实在资粮——**德**（厚道让人自来归）、**信**（说到做到让人心不贰）、**义**（公平赏罚让众人服）、**才**（能鉴古照今让人不觉得你空）、**明**（看得清下面真实情况不被蒙蔽）。落动作：五样逐项自评打分（1-5），最低分那一项就是你立威立德的短板，先补它。
- **求人之志·修身接人术（一串"所以"）**：「绝嗜禁欲，所以除累；博学切问，所以广知；高行微言，所以修身；恭俭谦约，所以自守；深计远虑，所以不穷；亲仁友直，所以扶颠；近恕笃行，所以接人；任材使能，所以济务；殚恶斥谗，所以止乱；推古验今，所以不惑。」（求人之志章）帝御化：这是一份**可逐条照做的修身—接人清单**——戒掉过度嗜好是为了免拖累；博学勤问是为了长见识；行登高言谨慎是为了修身；恭俭谦约是为了自守；深谋远虑是为了不困穷；亲近仁者、友交直士是为了将倾时有扶手；近恕道、笃实行是为了接得住人；量材任使是为了成事；斥退奸谗是为了止乱；推古验今是为了不糊涂。落动作：从这串里挑当前最缺的一两条，本周落地（如"近恕笃行所以接人"= 本周对每个队友多一份将心比心）。
- **务善策者无恶事，无远虑者有近忧**：「务善策者无恶事，无远虑者有近忧。」（本德宗道 / 安礼章）帝御化：选"善策"——对众人长期都好的决策——后事才不生恶；只图眼前省事、不愿想三个月后的账，近忧马上找上门。落判断：此刻这个"省力"的决定，三个月后会不会变成团队要替你收拾的烂摊子？会，就是恶策的种子。
- **畏危者安，畏亡者存（戒惧即保身）**：「畏危者安，畏亡者存。」（遵义 / 安礼章）帝御化：**常怀"这样下去会危、会亡"的戒惧，反而能安、能存**；肆无忌惮、觉得稳了的，才真会翻车。落判断：此刻你最该"怕"的是什么——是队伍散、是钱链断、是身体垮？把它写下来当成警钟，别等到了才怕。
- **小功不赏则大功不立，小怨不赦则大怨必生（赏罚之道）**：「小功不赏，则大功不立；小怨不赦，则大怨必生。赏不服人、罚不甘心者叛；赏及无功、罚及无罪者酷。」（遵义章）帝御化：**赏罚是带兵的硬杠杆**——小功劳不及时赏，就没人愿立大功；小过节不放下，就会攒成大怨恨；赏了让人心不服、罚了让人不甘心，队伍必叛；赏给没功的、罚给无罪的，就是酷政。落动作：复盘你的赏罚——最近有没有小功被你当成理所当然没赏？有没有旧怨一直没翻篇？赏罚是"当众及时、对事不对人"吗？
- **亲仁友直，所以扶颠；知足不贪，所以长吉**：「亲仁友直，所以扶颠。」（求人之志章）「吉莫吉于知足，苦莫苦于多愿。」（本德宗道章）帝御化：主动亲近**仁者**（存心厚道不坑人）与**直者**（敢当面说真话不捧场），这二人是你将倾未倾时的扶手；面谀者（只捡你爱听的说）是把你往坑里送的人。而最大的吉祥是知道"够了"，最大的苦是欲望太多、什么都想要——事成之后不收手，已得的会被多愿折进去。落动作：列三个人——谁是你身边的"仁"、谁是你的"直"，定期维护；同时问自己"现在够了吗"，不让多愿把人心与成果折进去。

## 三、适用场景清单

1. 修身立心：想系统补"德行"这一课，不知从哪下手。
2. 带团队立威立德：当了队长 / 团长 / 负责人，感觉人不服、心不齐，需要立威与立德并举。
3. 判断一个人德性根基：要深交、要重用、要托付核心，需先看其人可不可靠。
4. 临事做"善策还是权宜"的抉择：两个方案一个解眼前、一个利长远，不知怎么选。
5. 团队人心散了：士气低落、成员撂挑子，需要收心。
6. 赏罚失衡：干多干少一个样、旧怨堆积，队伍开始消极 / 叛离。
7. 自我评价不清：不知道自己在"德、信、义、才、明"上哪块短板最要命。
8. 顺境松懈：局面刚好转就觉得稳了、开始肆无忌惮，需要重新立戒惧。

## 四、推演逻辑链

1. **省五德**：自查当下缺哪一面——只讲规矩不讲人情（缺仁）？只讲人情不讲原则（缺义）？只埋头做不了解下情（缺明）？只许诺不兑现（缺信）？方向偏了（缺道）？裂哪面先补哪面。
2. **评五资**：德 / 信 / 义 / 才 / 明 五样逐项打分，找出最低分，定为本次要补的"立德短板"。
3. **辨善恶策**：把当前面临的选项逐条过——它是"善策"（对众人长期都好）还是"权宜"（只解眼前、留后患）？权宜项要么改、要么标风险。
4. **立戒惧（畏危）**：写下此刻最该"怕"的一件事（队伍散 / 钱链断 / 身体垮），把它当警钟，不让顺境冲昏头。
5. **整赏罚（遵义）**：过一遍赏罚——小功及时赏了吗？小怨放下了吗？赏罚是否对事不对人、让人甘心？缺哪条补哪条。
6. **咨仁直**：把选项说给你认定的仁者与直者听——仁者评"这事厚不厚道"，直者对"敢不敢当面戳破风险"；两人意见都收，不偏袒。
7. **立德为序**：方向定了之后，把"德"落成可执行的规矩——公平分工（义）、兑现承诺（信）、逐人照拂（明），让德行变成团队可预期的次序，而不是一句自我感动。
8. **知足守界**：事成之后主动问"够了吗"——见好就收，不让"多愿"把已到手的人心与成果折进去。

## 五、约束边界

1. 五德一体不是道德表演：德要落到"怀远、得众"的实际效果上——人真的因你而聚拢、事真的因你而顺，才算数；自我感动式的修养不算。
2. **修身是律己，不是拿五德当鞭子抽别人**：不能用"你不仁、你不义"去道德绑架队友或家人。
3. 务善 ≠ 当老好人：义者"赏善罚恶"，善策里本就含着对恶事、懒人、捣乱者的处置，不是无原则妥协。
4. 赏罚要及时、要甘心：小功不赏则大功不立——别把下属的小功劳当理所当然；但也不滥赏（赏及无功者酷）。
5. 知足不是不上进：是给"多愿"止损，与进取并行不悖——该争的资源照争，只是不贪到把盘子砸了。
6. 亲仁友直是择友标尺，不是拉帮结派：亲近仁者直者是为了扶正自己，不是搞小圈子排挤异己。

## 六、案例示例

**案例一（带队 · 立德收心）**：作为比赛团队 / 率土团长，只盯进度与战果，连开一周会没人情，老队员开始消极、新人不敢说话。
- 背景：礼（规矩、进度）做得很足，仁（关心人、照下）几乎为零——五德缺仁，人散。
- 走逻辑链：省五德——裂在"仁"与"明"；评五资——"明足以照下"最低（根本不知道谁状态不对）；辨善策——选"先收心再赶工"（善策，利队伍长期）而非"再压进度"（权宜，只会加速人走）；立戒惧——写下"再压下去老队员要走"这条警钟；咨仁直——找队里最直的老队员问"大家最近真实状态如何"，拿到真话；立德为序——此后重要任务前逐人一对一沟通状态、分工按贡献公平（补义）；知足守界——不因为赶工就承诺超出能力的交付。
- 结论：德不是空喊，是"明足以照下"那一通一对一的电话；立威先立德，德立住了威才立得住。

**案例二（带队 · 赏罚收心 / 遵义）**：RoboCon 队伍里，一个新人熬了三个通宵把机械臂调通（小功），你觉得"本来就该干"没表扬；另一个老队员上次失误你记到现在（小怨），导致新人寒心、老队员撂挑子。
- 背景：踩了"小功不赏则大功不立""小怨不赦则大怨必生"两条。
- 走逻辑链：省五德——裂在"义"（赏罚失宜）；整赏罚——本周当众肯定新人那次调试（小功即赏，立大功之志），私下跟老队员把上次失误翻篇（小怨即赦，免大怨）；咨仁直——找直队员确认"大家觉得最近公平吗"；立德为序——立下"进度贡献公开记录、及时肯定"的规则，赏对事不对人；立戒惧——记住"赏不服人则叛"。
- 结论：赏罚不是出大事才用，小功小怨的及时处置，才是队伍不散的日常。

**案例三（人生抉择 · 五资自评）**：同时被两个方向拉扯——一边是来钱快但要长期透支、看人下菜的活，一边是钱稳但能攒真本事的路。
- 走逻辑链：评五资——选第一条路，自己的"德、信"两资会在过程中持续折损（要做违心的事），且身边会聚拢面谀者；辨善策——第二条路是善策（对自己长期"资粮"好）；咨仁直——把纠结说给一位长者与一位敢直言的朋友听；知足守界——接受第二条路短期内"不够风光"，不因多愿眼红别人的快钱。
- 结论：选哪条路，不只看钱，看它是在给你的"五资"增值还是折旧。

## 七、与帝御体系联动

- **归层**：内炼之经。以**心法层**为主——主导诀「温」（德厚怀远、静而能容，以德养人）＋「恭」（明足以照下：宏观看团队整体心气，微观察每人真实状态）；辅以**御势层（统御率众）**——德威并施、赏罚收心，与《三略》"统御+收心"、《六韬》将略、《孙子》赏罚相参。
- **诀系**：温（德化怀远）+ 恭（照下察微）+ 俭（知足守界、绝嗜禁欲）+ 御势（统御 / 赏罚）。
- **与基础诀的根系联系（依 E05）**：「德足以怀远」即「温」之容——温者宏微百视心煅渊，德厚方能容人怀远；「明足以照下」即「恭」之察微——扶宏察微，于队伍上即看清整体又照见个体；「绝嗜禁欲所以除累」「吉莫吉于知足」即「俭」——积微累势、困俭节耗，圣必困俭；「畏危者安」即「让」与戒惧——知戒惧方知退让蓄势。
- **调度方式**：帝御定位处境为"修身 / 带队立德立威 / 赏罚失衡 / 判断人之德性根基"时，经万法归宗·内炼之经与御势之经索引触发本子技能，独立加载并按「推演逻辑链」执行；与主文件分工——主文件给"温、恭"的定性纲领与统御层口径，本文件给《素书》六章主干、五德一体、五资自评、求人之志修身术、遵义赏罚的完整修身—统御操作法；与《三略》分工——三略重"德威并施"的统御术，素书重"修身立德"的统御之本；与《止学》分工——素书"知足不贪"与止学"知止收手"互参，素书偏修身立人，止学偏贪进刹车。
